โปรแกรมแรก: REPL, Script, ตัวแปร ชนิดข้อมูล และตัวเลข

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

โปรแกรม คือชุดคำสั่งที่เราเขียนเรียงกันเพื่อบอกคอมพิวเตอร์ว่าต้องทำอะไรทีละขั้น ข้อความคำสั่งที่เราพิมพ์เรียกว่า Source Code คอมพิวเตอร์อ่านภาษา Python ตรง ๆ ไม่ได้ จึงต้องมีโปรแกรมตัวกลางชื่อ Interpreter (คือคำสั่ง python3) ทำหน้าที่อ่านโค้ดของเราทีละบรรทัดจากบนลงล่าง แล้วสั่งให้เครื่องทำงานตามนั้น

เราใช้ Python ได้ 2 แบบ แบบแรกคือ REPL (Read-Eval-Print Loop) เปิดด้วยการพิมพ์ python3 เฉย ๆ จะเห็นเครื่องหมาย >>> พิมพ์คำสั่งหนึ่งบรรทัดแล้วเห็นผลทันที เหมาะกับการทดลองสั้น ๆ แบบที่สองคือ Script คือไฟล์นามสกุล .py ที่เก็บคำสั่งหลายบรรทัด แล้วรันด้วย python3 ชื่อไฟล์.py เหมาะกับงานจริงเพราะบันทึกไว้แก้และรันซ้ำได้ จำความต่างให้ดี: ถ้าเห็น $ แปลว่าอยู่ใน Bash ให้พิมพ์คำสั่ง Linux ถ้าเห็น >>> แปลว่าอยู่ใน Python ให้พิมพ์โค้ด Python ออกจาก REPL ด้วย exit() หรือกด Ctrl+D และดูคู่มือได้ด้วย help(print) (กด q เพื่อออกจากหน้าคู่มือ)

Variable (ตัวแปร) คือชื่อที่เราตั้งให้ข้อมูล เพื่อเรียกใช้ภายหลัง เขียนแบบ price = 45 เครื่องหมาย = ใน Python แปลว่า "เอาค่าทางขวาใส่ชื่อทางซ้าย" ไม่ได้แปลว่า "เท่ากับ" แบบในวิชาคณิตศาสตร์ เราเปลี่ยนค่าตัวแปรได้ตลอด (Reassignment) กฎการตั้งชื่อมีดังนี้:

  • ใช้ตัวอักษรภาษาอังกฤษ ตัวเลข และ _ ได้ แต่ห้ามขึ้นต้นด้วยตัวเลข (2price ผิด)
  • ตัวพิมพ์เล็กกับตัวพิมพ์ใหญ่ถือเป็นคนละชื่อ (Price กับ price ต่างกัน)
  • ห้ามใช้คำสงวน เช่น if, for, class และไม่ควรตั้งทับชื่อฟังก์ชันที่มีอยู่ เช่น list, str, sum
  • ใช้รูปแบบ snake_case คือตัวพิมพ์เล็กคั่นด้วย _ เช่น discount_amount ตามมาตรฐาน PEP 8

ข้อมูลทุกค่ามี ชนิด (Type) ตรวจได้ด้วย type() ชนิดพื้นฐานที่ต้องรู้คือ int (จำนวนเต็ม), float (ทศนิยม), str (ข้อความ อยู่ในเครื่องหมายคำพูด), bool (True/False) และ None (ยังไม่มีค่า) ชนิดของข้อมูลกำหนดว่าทำอะไรกับมันได้บ้าง เช่น 45 + 3 ได้ 48 แต่ "45" + "3" ได้ "453" เราใช้ความรู้นี้ทุกครั้งที่เขียนโปรแกรม ตั้งแต่คำนวณราคาสินค้าไปจนถึงอ่านข้อมูลจากไฟล์

เปรียบเทียบ

ตัวแปรเหมือน กล่องที่แปะป้ายชื่อ ป้าย price แปะอยู่บนกล่องที่มีเลข 45 อยู่ข้างใน ถ้าเขียน price = 50 ก็คือเอาของในกล่องออกแล้วใส่ 50 แทน ส่วนชนิดข้อมูลเหมือน ประเภทของของในกล่อง กล่องเงินกับกล่องจดหมายใช้งานต่างกัน เอาเงินมาบวกกันได้ แต่เอาจดหมายมาบวกกันจะได้จดหมายที่ต่อกันยาวขึ้น ส่วน Interpreter เหมือน ล่ามแปลภาษา ที่อ่านคำสั่งของเราทีละประโยคแล้วแปลให้เครื่องเข้าใจ

# types_demo.py : ตัวแปร ชนิดข้อมูล และการคำนวณ
# ข้อมูลออเดอร์ 1 รายการของร้านเครื่องดื่ม
item = "ชาไทย"  # str = ข้อความ
price = 45  # int = จำนวนเต็ม (บาทต่อแก้ว)
qty = 3  # int
discount = 0.1  # float = ทศนิยม (ลด 10%)
is_member = True  # bool = จริง/เท็จ
coupon = None  # None = ยังไม่มีค่า

print("=== ข้อมูลออเดอร์ ===")
print("item      =", item, type(item))
print("price     =", price, type(price))
print("qty       =", qty, type(qty))
print("discount  =", discount, type(discount))
print("is_member =", is_member, type(is_member))
print("coupon    =", coupon, type(coupon))

# คำนวณราคา
subtotal = price * qty
discount_amount = subtotal * discount
total = subtotal - discount_amount
print("=== คำนวณราคา ===")
print("ราคารวมก่อนลด:", subtotal)
print("ส่วนลดสมาชิก:", discount_amount)
print("ยอดสุทธิ:", total)
print("ยอดสุทธิ (ปัด 2 ตำแหน่ง):", round(total, 2))

# แปลงชนิดข้อมูล
qty_text = "3"  # ข้อความที่หน้าตาเหมือนตัวเลข
print("=== แปลงชนิด ===")
print("int('3') * 45 =", int(qty_text) * price)
print("str(45) + ' บาท' =", str(price) + " บาท")
print("float(45) =", float(price))

# แปลงวินาทีเป็น ชั่วโมง นาที วินาที ด้วย // และ %

minutes = remain // 60
secs = remain % 60
print("=== แปลงเวลา ===")
print(seconds, "วินาที =", hours, "ชั่วโมง", minutes, "นาที", secs, "วินาที")

# ตัวดำเนินการและลำดับการคำนวณ

print("7 % 2 =", 7 % 2)
print("2 ** 10 =", 2**10)
print("2 + 3 * 4 =", 2 + 3 * 4)
print("(2 + 3) * 4 =", (2 + 3) * 4)

# ทศนิยมในคอมพิวเตอร์ไม่แม่นยำ 100%
print("=== float ===")
print("0.1 + 0.2 =", 0.1 + 0.2)
print("0.1 + 0.2 == 0.3 ->", 0.1 + 0.2 == 0.3)

String, f-string และการรับ Input จากผู้ใช้

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

String (ชนิด str) คือข้อความ เช่น ชื่อลูกค้า อีเมล หรือที่อยู่ ใน Python String คือ ลำดับของตัวอักษร แต่ละตัวมีเลขตำแหน่ง (Index) เริ่มจาก 0 ทางซ้าย และนับถอยหลังด้วยเลขติดลบจากทางขวา (-1 คือตัวสุดท้าย) เราตัดบางช่วงได้ด้วย Slicing รูปแบบ [start:stop:step] โดยได้ตั้งแต่ start ถึงก่อน stop สิ่งสำคัญคือ String แก้ไขไม่ได้ (Immutable) ทุก Method เช่น .upper() จะคืน String ใหม่ ไม่ได้แก้ตัวเดิม ตัวอักษรพิเศษเขียนด้วย Escape เช่น \n คือขึ้นบรรทัดใหม่ และ \t คือ Tab

งานจริงเกือบทุกงานต้องทำความสะอาดข้อความที่ผู้ใช้พิมพ์มา (ช่องว่างเกิน ตัวพิมพ์ใหญ่เล็กไม่สม่ำเสมอ) และต้องแสดงผลให้อ่านง่าย Method ที่ใช้บ่อยมีดังนี้:

  • strip() ตัดช่องว่างหัวท้าย, lower()/upper()/title() เปลี่ยนตัวพิมพ์
  • replace(old, new) แทนที่ข้อความ, split() แยกเป็น list, " ".join(list) ต่อ list กลับเป็นข้อความ
  • startswith()/endswith() ตรวจหัวท้าย และ "คำ" in ข้อความ ตรวจว่ามีคำนั้นอยู่ไหม
  • f-string คือ String ที่มี f นำหน้า ใส่ตัวแปรใน {} ได้ตรง ๆ และกำหนดรูปแบบได้ เช่น {x:,.2f} (คั่นหลักพัน ทศนิยม 2 ตำแหน่ง), {p:.1%} (เปอร์เซ็นต์), {s:>10} (ชิดขวากว้าง 10 ช่อง), {n:05d} (เติม 0 ข้างหน้าให้ครบ 5 หลัก) และ {x=} (แสดงทั้งชื่อและค่า ใช้ตอนดีบัก)

ส่วน input("ข้อความถาม") ใช้รับข้อมูลที่ผู้ใช้พิมพ์ทางคีย์บอร์ด จุดที่มือใหม่พลาดบ่อยที่สุดคือ input() คืนค่าเป็น str เสมอ แม้ผู้ใช้จะพิมพ์ตัวเลข ถ้าจะคำนวณต้องแปลงด้วย int() หรือ float() ก่อน

เปรียบเทียบ

String เหมือน ลูกปัดที่ร้อยอยู่บนเชือก ลูกปัดแต่ละเม็ดมีหมายเลขกำกับ เม็ดแรกคือเบอร์ 0 Slicing คือการตัดเชือกเอาลูกปัดบางช่วงมาเป็นสร้อยเส้นใหม่ โดยสร้อยเส้นเดิมไม่เสียหาย ส่วน f-string เหมือน แบบฟอร์มที่มีช่องว่างให้เติม เช่น "เรียนคุณ ____ ยอดชำระ ____ บาท" เราแค่บอกว่าช่องไหนใส่ค่าอะไรและจัดรูปแบบอย่างไร

โปรแกรมที่ทำงานจากบนลงล่างตรง ๆ ทำได้แค่งานง่าย งานจริงต้อง ตัดสินใจ (ถ้าคะแนนถึง 80 ให้เกรด A ถ้าไม่ถึงให้ดูเงื่อนไขถัดไป) และต้อง ทำซ้ำ (ตรวจข้อสอบ 40 คนด้วยกฎเดียวกัน) Python ใช้ if/elif/else สำหรับการตัดสินใจ และใช้ for/while สำหรับการทำซ้ำ

เงื่อนไขสร้างจาก ตัวดำเนินการเปรียบเทียบ == (เท่ากับ), != (ไม่เท่ากับ), <, <=, >, >= และรวมเงื่อนไขด้วย and, or, not Python เขียนช่วงแบบคณิตศาสตร์ได้ เช่น 0 <= score <= 100 ค่าบางค่าถูกมองเป็น "เท็จ" อัตโนมัติ (Falsy) ได้แก่ 0, 0.0, "", [], {} และ None ส่วนค่าอื่นเป็น "จริง" (Truthy) เราจึงเขียน if name: แทน if name != "": ได้

สิ่งที่ต้องเข้าใจเกี่ยวกับ Loop มีดังนี้:

  • บล็อกคำสั่งกำหนดด้วยการย่อหน้า (Indentation) 4 ช่องว่าง ทุกบรรทัดที่ย่อหน้าเท่ากันใต้ if หรือ for คือบล็อกเดียวกัน และบรรทัด if/for/while ต้องจบด้วย :

  • for ใช้วนตามสมาชิกของ list หรือ String ส่วน range(start, stop, step) สร้างลำดับตัวเลข และ enumerate(list, start=1) ให้ทั้งลำดับที่และค่า
  • while วนไปเรื่อย ๆ ตราบที่เงื่อนไขยังจริง ต้องเปลี่ยนค่าที่ใช้ในเงื่อนไขทุกรอบ ไม่อย่างนั้นจะเป็น Infinite Loop (กด Ctrl+C เพื่อหยุด)
  • break ออกจาก Loop ทันที, continue ข้ามไปรอบถัดไป และ for ... else/while ... else จะทำบล็อก else เมื่อ Loop จบครบโดยไม่โดน break

scores = [95, 82, 74, 61, 48, 105]

    if score == 0:
        print("พบคะแนน 0 หยุดตรวจทันที")
        break  # ออกจาก loop ทันที
    if score < 0 or score > 100:
        print(f"คนที่ {no}: คะแนน {score} ไม่ถูกต้อง ข้าม")
        continue  # ข้ามไปรอบถัดไป

        grade = "B"

        grade = "C"

    # for-else: ทำงานเมื่อ loop จบครบโดยไม่เจอ break

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

Function คือชุดคำสั่งที่ตั้งชื่อไว้แล้วเรียกใช้ซ้ำได้ เราใช้ Function มาตั้งแต่แนวคิดแรกแล้ว เช่น print(), len(), round() ตอนนี้เราจะสร้าง Function ของเราเองด้วย def เหตุผลที่ต้องใช้มี 3 ข้อ (1) ใช้ซ้ำ เขียนสูตรตัดเกรดครั้งเดียวแล้วเรียกได้ทุกที่ (2) ตั้งชื่อให้ความคิด vat(price) อ่านเข้าใจทันทีกว่าสูตรยาว ๆ (3) ทดสอบได้ Function ที่รับค่าแล้วคืนค่า ตรวจได้ง่ายด้วย pytest (แนวคิดที่ 12) กฎง่าย ๆ คือ ถ้าเขียนโค้ดเดียวกันซ้ำครั้งที่สาม ให้แยกเป็น Function

คำศัพท์ที่ต้องแยกให้ออก: Parameter คือชื่อตัวแปรที่ประกาศไว้ใน def ส่วน Argument คือค่าจริงที่ส่งตอนเรียก รายละเอียดที่ต้องรู้มีดังนี้:

  • Positional ส่งตามลำดับ vat(1000, 0.1) และ Keyword ส่งด้วยชื่อ vat(1000, rate=0.1) แบบ Keyword อ่านง่ายกว่าเมื่อมีหลาย Argument
  • Default rate: float = 0.07 ทำให้ไม่ต้องส่งค่านั้นทุกครั้ง
  • return ส่งผลลัพธ์กลับไปให้ผู้เรียกใช้ต่อ ต่างจาก print ที่แค่แสดงบนจอ Function ที่ไม่มี return จะคืน None และถ้า return a, b จะได้ tuple
  • Scope ตัวแปรที่สร้างใน Function เป็น Local ใช้ได้แค่ข้างใน ไม่กระทบตัวแปร Global ชื่อเดียวกัน
  • *args รับ Positional กี่ตัวก็ได้ (ได้เป็น tuple) และ **kwargs รับ Keyword กี่ตัวก็ได้ (ได้เป็น dict) Parameter ที่อยู่หลัง * เดี่ยว ๆ ต้องส่งแบบ Keyword เท่านั้น (Keyword-only)
  • Type Hint เช่น score: int, -> str, list[float], dict[str, int], str | None เป็นคำอธิบายให้คนและเครื่องมืออย่าง VS Code (Pylance) หรือ mypy ตรวจ แต่ Python ไม่บังคับตอนรัน
  • Docstring คือข้อความใน """...""" บรรทัดแรกใต้ def แสดงผ่าน help(vat) หรือ vat.__doc__ และ VS Code จะโชว์ตอนเอาเมาส์ชี้
เปรียบเทียบ

Function เหมือน เครื่องชงกาแฟอัตโนมัติ Parameter คือช่องใส่ของที่ออกแบบไว้ (เมล็ดกาแฟ นม ระดับความหวาน) Argument คือของจริงที่เราใส่ตอนกดชง ค่า Default คือ "หวานปกติ" ถ้าไม่เลือก return คือแก้วกาแฟที่ไหลออกมาให้เราถือไปใช้ต่อ ส่วน print เหมือนเครื่องแค่ขึ้นข้อความบนหน้าจอว่า "ชงแล้ว" แต่ไม่มีแก้วออกมา Docstring คือฉลากวิธีใช้ที่แปะข้างเครื่อง

def grade(score: int) -> str:
    """คืนเกรด A-F จากคะแนน 0-100"""
    if score >= 80:
        return "A"
    if score >= 70:
        return "B"
    if score >= 60:
        return "C"
    if score >= 50:
        return "D"
    return "F"


def average(*numbers: float) -> float:
    """หาค่าเฉลี่ยของตัวเลขกี่ตัวก็ได้"""
    if not numbers:
        raise ValueError("ต้องส่งตัวเลขอย่างน้อย 1 ตัว")
    return sum(numbers) / len(numbers)


def vat(amount: float, rate: float = 0.07) -> float:
    """คำนวณภาษีมูลค่าเพิ่ม

    amount: ราคาก่อนภาษี
    rate: อัตราภาษี ค่าเริ่มต้น 0.07 (7%)
    """
    return round(amount * rate, 2)


def describe(name: str, **info: str) -> str:
    """สร้างข้อความแนะนำตัวจากข้อมูลที่ส่งมาแบบ keyword"""
    details = ", ".join(f"{key}={value}" for key, value in info.items())
    return f"{name} ({details})"


def split_bill(total: float, people: int, *, tip: float = 0.0) -> tuple[float, float]:
    """หารค่าอาหาร คืน (ยอดรวมทิป, ยอดต่อคน) โดย tip ต้องส่งแบบ keyword"""
    grand_total = total * (1 + tip)
    return round(grand_total, 2), round(grand_total / people, 2)

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

เมื่อโปรแกรมยาวขึ้น การเขียนทุกอย่างในไฟล์เดียวจะอ่านยากและแก้ยาก Python แบ่งโค้ดเป็นชิ้นได้ 2 ระดับ Module คือไฟล์ .py หนึ่งไฟล์ ไฟล์อื่นนำไปใช้ได้ด้วย import convert, from convert import format_baht หรือ import datetime as dt (ตั้งชื่อย่อ) ส่วน Package คือโฟลเดอร์ที่รวมหลาย Module และมีไฟล์ __init__.py ซึ่งทำงานตอนที่ Package ถูก import ครั้งแรก นิยมใช้เลือกว่าจะเปิดให้ภายนอกใช้ Function ไหนบ้าง

ตอน import Python จะหา Module ตามรายการโฟลเดอร์ใน sys.path โดย โฟลเดอร์ของ Script ที่รันอยู่มาก่อน แล้วจึงเป็น Standard Library และ Package ใน venv ผลที่ตามมาคือ ถ้าเราตั้งชื่อไฟล์ว่า random.py, csv.py หรือ requests.py Python จะ import ไฟล์ของเราแทนของจริง ทุกไฟล์ยังมีตัวแปรพิเศษ __name__ ถ้ารันไฟล์นั้นโดยตรง ค่าจะเป็น "__main__" ถ้าถูก import ค่าจะเป็นชื่อ Module เราจึงเขียน if __name__ == "__main__": เพื่อแยก "โค้ดที่รันเมื่อเป็นโปรแกรมหลัก" ออกจาก "Function ที่ให้คนอื่น import"

ส่วน Package ภายนอก เช่น requests มาจาก PyPI (pypi.org) และติดตั้งด้วย pip บน Ubuntu 24.04 ระบบห้ามติดตั้งลง Python ของระบบโดยตรง (มาตรฐาน PEP 668) เพราะ Ubuntu เองก็ใช้ Python ทำงานหลายอย่าง ถ้า Package ของเราไปทับเวอร์ชันที่ระบบต้องการ เครื่องมือของระบบอาจพัง ทางแก้คือ Virtual Environment (venv) ซึ่งเป็นโฟลเดอร์ .venv ที่มี Python และ Package แยกเฉพาะโปรเจกต์ แล้วบันทึกรายชื่อ Package พร้อมเวอร์ชันลง requirements.txt ให้คนอื่นสร้างสภาพแวดล้อมเหมือนเราได้ทุกตัวอักษร

เปรียบเทียบ

Module เหมือน บทหนึ่งในหนังสือ Package เหมือน หนังสือทั้งเล่ม ที่มีสารบัญ (__init__.py) ส่วน venv เหมือน กล่องเครื่องมือของแต่ละงาน ช่างไฟกับช่างประปามีกล่องของตัวเอง ไม่หยิบเครื่องมือของบ้าน (ระบบ) ไปใช้จนพัง และ requirements.txt คือ ใบรายการเครื่องมือ ที่ระบุยี่ห้อและรุ่น ใครได้ใบนี้ไปก็จัดกล่องได้เหมือนกันทุกชิ้น

    response = requests.get(url, timeout=5)  # รอไม่เกิน 5 วินาที

    response.raise_for_status()  # ถ้าเป็น 4xx/5xx จะโยน HTTPError

def main() -> None:

    for currency, rate in data["rates"].items():

if __name__ == "__main__":
    main()

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

ตัวแปรทุกตัวหายไปเมื่อโปรแกรมจบ ถ้าอยากเก็บข้อมูลไว้ใช้ครั้งหน้า ต้องเขียนลง ไฟล์ งานจริงที่ใช้ Python มากที่สุดงานหนึ่งคือ "อ่านไฟล์ ประมวลผล แล้วเขียนผลลัพธ์" เช่น รวมยอดขายจาก CSV ที่ Excel ส่งออกมา หรือบันทึกการตั้งค่าเป็น JSON แนวคิดนี้ใช้เครื่องมือในตัว Python ทั้งหมด ไม่ต้องติดตั้งเพิ่ม

  • pathlib.Path แทนที่อยู่ไฟล์เป็น Object ต่อ Path ด้วย / เช่น BASE_DIR / "data" / "expenses.csv" มี .exists(), .mkdir(parents=True, exist_ok=True), .glob("*.csv"), .read_text()/.write_text() และส่วนประกอบชื่อ .name, .suffix, .stem ใช้ได้เหมือนกันทั้ง Linux และ Windows
  • open(path, mode, encoding=...) โหมด "r" อ่าน (ค่าเริ่มต้น), "w" เขียนทับ (ไฟล์เดิมหายทันที), "a" เขียนต่อท้าย ใช้คู่กับ with เสมอ เพื่อให้ไฟล์ถูกปิดอัตโนมัติแม้เกิด Error
  • encoding="utf-8" ต้องใส่ทุกครั้งที่มีภาษาไทย และใส่ newline="" ทุกครั้งที่เปิดไฟล์ให้ Module csv
  • csv.DictReader อ่านแต่ละแถวเป็น dict โดยใช้หัวตารางเป็น key (ค่าทุกช่องเป็น str ต้องแปลงเอง) และ csv.DictWriter เขียน dict เป็นแถว เรียก writeheader() ก่อน
  • json.dump/json.load แปลง dict/list ไปเป็นไฟล์ JSON และกลับมา ใส่ ensure_ascii=False ให้ภาษาไทยอ่านออก และ indent=2 ให้จัดบรรทัดสวย

"""อ่านไฟล์ค่าใช้จ่าย CSV สรุปยอดเดือนตุลาคม แล้วบันทึกเป็น JSON"""

import csv
import json
from pathlib import Path

BASE_DIR = Path(__file__).parent  # โฟลเดอร์ที่ไฟล์ .py นี้อยู่ ไม่ขึ้นกับว่ารันจากไหน
DATA_DIR = BASE_DIR / "data"
CSV_PATH = DATA_DIR / "expenses.csv"
MONTH = "2026-10"


def load_expenses(path: Path) -> list[dict[str, str]]:
    """อ่าน CSV ทุกแถวเป็น list ของ dict (ค่าทุกช่องเป็น str)"""
    with open(path, encoding="utf-8", newline="") as f:
        return list(csv.DictReader(f))


def summarize(rows: list[dict[str, str]], month: str) -> dict[str, float]:
    """รวมยอดแยกตามหมวด เฉพาะรายการในเดือนที่กำหนด"""
    totals: dict[str, float] = {}
    for row in rows:
        if not row["date"].startswith(month):
            continue
        amount = float(row["amount"])  # แปลงข้อความเป็นตัวเลข
        totals[row["category"]] = totals.get(row["category"], 0.0) + amount
    return totals


def main() -> None:
    print("ไฟล์:", CSV_PATH.name, "| นามสกุล:", CSV_PATH.suffix)
    print("มีไฟล์อยู่จริง:", CSV_PATH.exists())
    rows = load_expenses(CSV_PATH)
    print("อ่านได้", len(rows), "รายการ แถวแรก:", rows[0])

    totals = summarize(rows, MONTH)
    print(f"ยอดรวมเดือน {MONTH}:", sum(totals.values()))
    print("แยกตามหมวด:", totals)

    # บันทึก JSON ภาษาไทยอ่านออก
    out_path = DATA_DIR / f"summary-{MONTH}.json"
    report = {"month": MONTH, "total": sum(totals.values()), "by_category": totals}
    with open(out_path, "w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)
    print("บันทึกแล้ว:", out_path.relative_to(BASE_DIR))

    # อ่านกลับมาตรวจ
    with open(out_path, encoding="utf-8") as f:
        loaded = json.load(f)
    print("อ่านกลับ total =", loaded["total"], "| ตรงกัน:", loaded == report)

    # เพิ่มบรรทัดลงไฟล์ log ด้วยโหมด "a" (ต่อท้าย ไม่ลบของเดิม)
    log_path = DATA_DIR / "run.log"
    with open(log_path, "a", encoding="utf-8") as f:
        f.write(f"สรุปเดือน {MONTH} ได้ {len(totals)} หมวด\n")
    print("run.log มี", len(log_path.read_text(encoding="utf-8").splitlines()), "บรรทัด")

    # เขียน CSV ใหม่ด้วย DictWriter
    out_csv = DATA_DIR / f"by-category-{MONTH}.csv"
    with open(out_csv, "w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=["category", "total"])
        writer.writeheader()
        for category, total in sorted(totals.items()):
            writer.writerow({"category": category, "total": f"{total:.2f}"})

    # ไฟล์ .csv ทั้งหมดในโฟลเดอร์ data
    for csv_file in sorted(DATA_DIR.glob("*.csv")):
        print("พบไฟล์ CSV:", csv_file.name, "| stem:", csv_file.stem)


if __name__ == "__main__":
    main()

Exceptions และการ Debug: try/except/else/finally, raise, Custom Exception และ pdb

คืออะไร ทำไมต้องใช้ และใช้เมื่อไร

Exception คือสัญญาณว่าเกิดเหตุผิดปกติระหว่างรัน เช่น แปลง "abc" เป็นตัวเลขไม่ได้ (ValueError) หาไฟล์ไม่เจอ (FileNotFoundError) หรือหารด้วยศูนย์ (ZeroDivisionError) ถ้าไม่มีใครจัดการ โปรแกรมจะหยุดและพิมพ์ Traceback ออกมา วิธีอ่าน Traceback คือ อ่านจากล่างขึ้นบน: บรรทัดสุดท้ายบอกชนิด Error และข้อความ บรรทัดเหนือขึ้นไปบอกไฟล์และเลขบรรทัดที่เกิดเหตุ และไล่ขึ้นไปคือลำดับการเรียก Function ที่พามาถึงจุดนั้น

โค้ดที่ดีไม่ได้ป้องกันไม่ให้เกิด Error ทุกกรณี แต่ จัดการ Error ที่คาดได้อย่างตั้งใจ และแสดงข้อความที่ผู้ใช้เข้าใจ โครงสร้างที่ใช้มีดังนี้:

  • try: ครอบโค้ดที่อาจพัง, except ValueError as e: จับเฉพาะชนิดที่รู้วิธีจัดการ (มีหลาย except ได้), else: ทำเมื่อ try ไม่มี Error, finally: ทำทุกครั้ง เหมาะกับงานเก็บกวาด
  • raise ValueError("ข้อความชัดเจน") โยน Error เองเมื่อข้อมูลผิดกฎ และสร้าง Custom Exception ด้วยการสืบทอด เช่น class InvalidAmountError(ValueError) ผู้เรียกจึงจับได้ทั้งแบบเจาะจงและแบบกว้าง
  • raise NewError(...) from e แปลง Error ทางเทคนิคเป็น Error ของแอป โดยเก็บต้นเหตุไว้ใน __cause__ สำหรับดีบัก
  • ห้ามเขียน except: เปล่า ๆ หรือ except Exception: pass เพราะจะกลืนทุก Error รวมถึงบั๊กที่เราพิมพ์ผิดเอง ทำให้หาสาเหตุไม่เจอ

เมื่อโปรแกรมทำงานผิดแต่ไม่มี Error เราต้อง Debug วิธีพื้นฐานคือ print ค่าด้วย print(f"{amount=}") วิธีที่ทรงพลังกว่าคือ breakpoint() ซึ่งหยุดโปรแกรมแล้วเปิด pdb ให้พิมพ์คำสั่งดูค่าได้: p ตัวแปร (ดูค่า), n (ไปบรรทัดถัดไป), s (ก้าวเข้าไปใน Function), c (รันต่อจนถึงจุดหยุดถัดไป), l (ดูโค้ดรอบ ๆ), w (ดูลำดับการเรียก) และ q (ออก) ตั้ง PYTHONBREAKPOINT=0 เพื่อปิดทุก breakpoint() ชั่วคราว ใน VS Code ใช้ Debugger แบบกราฟิกได้: คลิกหน้าเลขบรรทัดหรือกด F9 เพื่อตั้ง Breakpoint แล้วกด F5 เลือก Python Debugger: Current File ค่าตัวแปรจะแสดงในแผง Variables ด้านซ้าย

เปรียบเทียบ

try/except เหมือน ตาข่ายใต้นักกายกรรม ถ้าพลาดตกลงมา (Exception) ตาข่ายรับไว้และการแสดงดำเนินต่อได้ แต่ตาข่ายต้องกางเฉพาะจุดที่เสี่ยง ถ้ากางคลุมทั้งเวที (except Exception) คนดูจะไม่รู้เลยว่ามีใครตกบ้าง finally เหมือน การปิดไฟเวทีหลังจบการแสดง ทำทุกครั้งไม่ว่าการแสดงจะราบรื่นหรือไม่ ส่วน Traceback เหมือน รายงานอุบัติเหตุ บรรทัดล่างสุดบอกว่าเกิดอะไรขึ้น บรรทัดบนบอกเส้นทางที่พามาถึงจุดเกิดเหตุ

"""แปลงข้อความจำนวนเงินอย่างปลอดภัย พร้อม Custom Exception"""


class InvalidAmountError(ValueError):
    """จำนวนเงินไม่ถูกต้องตามกฎของแอป"""


def parse_amount(text: str) -> float:
    """แปลงข้อความเป็นจำนวนเงิน ต้องมากกว่า 0 และทศนิยมไม่เกิน 2 ตำแหน่ง"""
    cleaned = text.replace(",", "").strip()  # ตัดเครื่องหมายคั่นหลักพัน
    try:
        amount = float(cleaned)
    except ValueError as e:
        # แปลง Error ทางเทคนิคเป็นข้อความที่ผู้ใช้เข้าใจ และเก็บต้นเหตุไว้
        raise InvalidAmountError(f"'{text}' ไม่ใช่ตัวเลข") from e
    if amount <= 0:
        raise InvalidAmountError(f"จำนวนเงินต้องมากกว่า 0 (ได้ {amount})")
    if "." in cleaned and len(cleaned.split(".")[1]) > 2:
        raise InvalidAmountError(f"'{text}' มีทศนิยมเกิน 2 ตำแหน่ง")
    return amount


def main() -> None:
    inputs = ["89.50", "abc", "-20", "120.555", "1,250.50"]
    processed = 0
    total = 0.0
    for text in inputs:
        try:
            amount = parse_amount(text)
        except InvalidAmountError as e:
            print(f"ข้าม: {e}")
        else:
            # ทำงานเฉพาะเมื่อ try ไม่มี Error
            total += amount
            print(f"OK: {text!r} -> {amount:,.2f}")
        finally:
            # ทำงานทุกครั้ง ไม่ว่าจะมี Error หรือไม่
            processed += 1
    print(f"ตรวจแล้ว {processed} รายการ | ยอดรวมที่ถูกต้อง {total:,.2f} บาท")

    # ดูต้นเหตุ (__cause__) ที่เก็บไว้ด้วย raise ... from e
    try:
        parse_amount("abc")
    except InvalidAmountError as e:
        print("ชนิด Error:", type(e).__name__, "| ต้นเหตุ:", repr(e.__cause__))
        print("เป็น ValueError ด้วยไหม:", isinstance(e, ValueError))


if __name__ == "__main__":
    main()

  • ครอบ try ให้แคบที่สุด เฉพาะบรรทัดที่อาจพัง และจับ Exception ชนิดที่เจาะจงที่สุด

  • datetime: date.fromisoformat("2026-10-19") แปลงข้อความเป็นวันที่, timedelta(days=30) บวกลบวัน, ลบวันที่กันได้ timedelta แล้วดู .days, strftime("%d/%m/%Y") จัดรูปแบบแสดงผล ส่วน date.today() ให้วันที่ปัจจุบันซึ่งต่างกันทุกวัน
  • collections: Counter นับความถี่และมี .most_common(n), defaultdict(float) สร้างค่าเริ่มต้นให้ key ใหม่อัตโนมัติ เหมาะกับรวมยอดตามกลุ่ม และ namedtuple("Point", "lat lon") สร้าง tuple ที่เรียกค่าด้วยชื่อได้
  • itertools: accumulate ยอดสะสม, groupby จัดกลุ่มรายการที่ติดกัน (ต้องเรียงก่อน), chain ต่อหลาย list เป็นสายเดียว, islice ตัดช่วงจาก Iterator
  • random กับ secrets: random (seed, choice, sample, shuffle) ใช้กับเกมและการจำลอง ใส่ random.seed(42) เมื่ออยากได้ผลเดิมทุกครั้ง ส่วน secrets (token_urlsafe, choice) ใช้กับรหัสผ่านและ Token เพราะเดาไม่ได้
  • argparse: รับ Argument จาก Command Line ทั้งแบบ Positional และ Option (--month) พร้อมแปลงชนิด (type=int, type=float), ค่า Default, จำกัดตัวเลือก (choices) และสร้างหน้า --help ให้อัตโนมัติ
  • logging: บันทึกเหตุการณ์ตามระดับ DEBUG < INFO < WARNING < ERROR < CRITICAL ส่งไปหลายปลายทางได้ด้วย Handler ใช้ logger = logging.getLogger(__name__) ในทุก Module
เปรียบเทียบ

Standard Library เหมือน กล่องเครื่องมือที่แถมมากับบ้านใหม่ มีทั้งไขควง ค้อน ตลับเมตร ไม่ต้องไปซื้อเพิ่มสำหรับงานทั่วไป argparse เหมือน แบบฟอร์มรับออเดอร์ ที่บังคับว่าช่องไหนต้องกรอก ช่องไหนเลือกได้ และมีคำอธิบายพิมพ์ไว้ด้านหลัง logging เหมือน สมุดบันทึกเวรของ รปภ. เรื่องเล็กจดลงสมุดอย่างเดียว (DEBUG, INFO ลงไฟล์) เรื่องสำคัญต้องแจ้งหัวหน้าทันที (WARNING ขึ้นจอ)

"""สถิติค่าใช้จ่ายรายเดือน: ตัวอย่าง Standard Library ที่ใช้บ่อย"""

import argparse
import csv
import logging
import random
import secrets
from collections import Counter, defaultdict
from datetime import date, timedelta
from itertools import accumulate, groupby
from pathlib import Path

logger = logging.getLogger(__name__)
CATEGORIES = [
    "food",
    "transport",
    "bills",
    "shopping",
    "health",
    "entertainment",
    "other",
]


def setup_logging(log_file: Path) -> None:
    """ส่ง Log ทุกระดับลงไฟล์ และแสดงบนจอเฉพาะ WARNING ขึ้นไป"""
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setLevel(logging.DEBUG)
    screen_handler = logging.StreamHandler()
    screen_handler.setLevel(logging.WARNING)
    logging.basicConfig(
        level=logging.DEBUG,
        format="%(asctime)s %(levelname)s %(name)s: %(message)s",
        handlers=[file_handler, screen_handler],
    )


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    """กำหนด Argument ของโปรแกรม argparse สร้าง --help ให้อัตโนมัติ"""
    parser = argparse.ArgumentParser(description="สรุปสถิติค่าใช้จ่ายรายเดือน")
    parser.add_argument("csv_file", type=Path, help="ไฟล์ CSV ค่าใช้จ่าย")
    parser.add_argument("--month", default="2026-10", help="เดือน YYYY-MM")
    parser.add_argument("--top", type=int, default=3, help="จำนวนหมวดยอดนิยม")
    parser.add_argument(
        "--min-amount", type=float, default=0.0, help="นับเฉพาะรายการที่ไม่ต่ำกว่าค่านี้"
    )
    parser.add_argument("--category", choices=CATEGORIES, help="ดูเฉพาะหมวดนี้")
    return parser.parse_args(argv)


def main(argv: list[str] | None = None) -> None:
    args = parse_args(argv)
    setup_logging(Path("app.log"))

    with open(args.csv_file, encoding="utf-8", newline="") as f:
        rows = list(csv.DictReader(f))
    logger.info("อ่าน %d รายการ จาก %s", len(rows), args.csv_file)

    month_rows = [
        r
        for r in rows
        if r["date"].startswith(args.month)
        and float(r["amount"]) >= args.min_amount
        and (args.category is None or r["category"] == args.category)
    ]
    if not month_rows:
        logger.warning("ไม่พบข้อมูลของเดือน %s", args.month)
        return

    # defaultdict(float): key ใหม่เริ่มที่ 0.0 อัตโนมัติ
    totals: defaultdict[str, float] = defaultdict(float)
    for r in month_rows:
        totals[r["category"]] += float(r["amount"])
    print(f"== ยอดรวมแยกหมวด เดือน {args.month} ==")
    for category, total in sorted(totals.items(), key=lambda kv: kv[1], reverse=True):
        print(f"{category:<10}{total:>10,.2f}")

    # Counter: นับจำนวนครั้ง แล้วเอาอันดับต้น ๆ
    counts = Counter(r["category"] for r in month_rows)
    print(f"== {args.top} หมวดที่ใช้บ่อยที่สุด ==", counts.most_common(args.top))

    # datetime: แปลงข้อความเป็นวันที่ แล้วหาระยะห่าง
    dates = [date.fromisoformat(r["date"]) for r in month_rows]
    first, last = min(dates), max(dates)
    print("ช่วงวันที่:", first.strftime("%d/%m/%Y"), "ถึง", last.strftime("%d/%m/%Y"))
    print(
        "ห่างกัน:",
        (last - first).days,
        "วัน | อีก 30 วันหลังรายการสุดท้าย:",
        last + timedelta(days=30),
    )

    # itertools.accumulate: ยอดสะสมทีละรายการ
    amounts = [float(r["amount"]) for r in month_rows]
    print("ยอดสะสม:", list(accumulate(amounts)))

    # itertools.groupby: ต้องเรียงตาม key ก่อน
    by_cat = sorted(month_rows, key=lambda r: r["category"])
    for category, group in groupby(by_cat, key=lambda r: r["category"]):
        print(f"กลุ่ม {category}:", [r["note"] for r in group])

    # random สำหรับจำลอง (seed ทำให้ผลซ้ำได้) และ secrets สำหรับความปลอดภัย
    random.seed(42)
    print("สุ่มรายการมาตรวจ:", random.choice(month_rows)["note"])
    print("สุ่ม 2 หมวด:", random.sample(sorted(totals), 2))
    token = secrets.token_urlsafe(16)
    print("ความยาว token สำหรับลิงก์รีเซ็ตรหัสผ่าน:", len(token), "ตัวอักษร")
    logger.debug("สรุปเสร็จ %d หมวด", len(totals))


if __name__ == "__main__":
    main()

Best Practice
  • ใช้ logging แทน print สำหรับข้อความวินิจฉัย ปรับระดับได้โดยไม่ต้องแก้โค้ด และ Log ลงไฟล์ไว้ตรวจย้อนหลังได้
  • เก็บวันที่ในไฟล์และฐานข้อมูลเป็น ISO 8601 (2026-10-19) และแปลงเป็นรูปแบบไทยเฉพาะตอนแสดงผล
  • CLI ทุกตัวควรมี main(argv=None) ที่รับ list ได้ เพื่อเขียน Test เรียกตรง ๆ โดยไม่ต้องเปิด Terminal
  • ใช้ secrets กับรหัสผ่าน Token และ OTP เสมอ ใช้ random.seed() เมื่อต้องการผลจำลองที่ทำซ้ำได้

จนถึงตอนนี้เราเก็บข้อมูลใน dict และเขียน Function แยกไว้ต่างหาก เมื่อโปรแกรมใหญ่ขึ้น ข้อมูลกับกฎที่ใช้กับข้อมูลนั้นควรอยู่ด้วยกัน Object-Oriented Programming (OOP) คือการจัดโค้ดเป็น Class ซึ่งเป็นแม่แบบที่บอกว่าของชนิดนี้มีข้อมูลอะไร (Attribute) และทำอะไรได้ (Method) แล้วสร้าง Object หลายชิ้นจากแม่แบบเดียว เช่น Class Account หนึ่งตัว สร้างบัญชีของสมชายและสมศรีได้ แต่ละบัญชีมียอดเงินของตัวเอง ข้อดีคือ กฎ "ห้ามถอนเกินยอด" เขียนไว้ที่เดียวใน Method withdraw ไม่มีใครแก้ยอดเงินผิดกฎจากที่อื่นได้

ส่วนประกอบสำคัญมีดังนี้:

  • __init__(self, ...) ทำงานตอนสร้าง Object self คือ Object ตัวที่กำลังถูกใช้ Python ส่งให้อัตโนมัติ จึงต้องเป็น Parameter แรกของทุก Method
  • Instance Attribute (self.owner) เป็นของแต่ละ Object ส่วน Class Attribute (ประกาศใต้ class) ใช้ร่วมกันทุก Object
  • __str__ คือข้อความสำหรับผู้ใช้ (ใช้โดย print) และ __repr__ คือข้อความสำหรับนักพัฒนา ควรบอกวิธีสร้าง Object นั้นซ้ำได้
  • Inheritance class SavingsAccount(Account) สืบทอดทุกอย่างจาก Class แม่ เรียก super().__init__(...) ให้แม่ตั้งค่าส่วนของตัวเอง และ Override คือเขียน Method ชื่อเดิมทับเพื่อเปลี่ยนพฤติกรรม
  • @property ทำให้ Method ถูกเรียกเหมือน Attribute (acc.balance) ถ้าไม่มี Setter จะอ่านได้อย่างเดียว ถ้าต้องการให้แก้ได้แต่ตรวจค่าก่อน ให้เพิ่ม @balance.setter
  • @classmethod รับ cls แทน self ใช้สร้าง Alternate Constructor เช่น Expense.from_row(row)
  • Composition over Inheritance: ถ้าความสัมพันธ์คือ "มี" (งบประมาณ มี รายการค่าใช้จ่าย) ให้เก็บ Object ไว้ใน Attribute ใช้ Inheritance เฉพาะเมื่อเป็น "เป็น" จริง (บัญชีออมทรัพย์ เป็น บัญชี)

@dataclass ช่วยเขียน Class ที่เน้นเก็บข้อมูลโดยสร้าง __init__, __repr__ และ __eq__ ให้อัตโนมัติจาก Type Hint ตัวเลือกที่ใช้บ่อยคือ field(default_factory=list) สำหรับค่าเริ่มต้นที่เป็น list, frozen=True ทำให้แก้ไม่ได้, order=True ทำให้เปรียบเทียบมากน้อยได้ และ __post_init__ สำหรับตรวจค่าหลังสร้าง Dataclass ดีกว่า dict เมื่อข้อมูลมีโครงสร้างตายตัว เพราะพิมพ์ชื่อ Field ผิดจะเจอ Error ทันที VS Code เติมชื่อให้ได้ และใส่การตรวจความถูกต้องไว้ในตัว ส่วนเรื่องเงินให้ใช้ decimal.Decimal แทน float เพื่อไม่ให้เจอปัญหา 0.1 + 0.2 จากแนวคิดที่ 1

เปรียบเทียบ

Class เหมือน แบบพิมพ์ขนมครก ส่วน Object คือ ขนมครกแต่ละลูก ที่ออกมาจากแบบพิมพ์เดียวกัน แต่ละลูกใส่หน้าต่างกันได้ (Attribute ต่างกัน) Inheritance เหมือน สูตรอาหารที่ต่อยอดจากสูตรแม่ สูตรขนมครกใบเตยใช้ทุกอย่างจากสูตรดั้งเดิมแล้วเพิ่มใบเตย @property แบบไม่มี Setter เหมือน หน้าจอแสดงยอดเงินบนตู้ ATM ดูได้ แต่จะแก้ตัวเลขต้องผ่านปุ่มฝากหรือถอนเท่านั้น

"""OOP: Class, Inheritance, @property, @classmethod และ Dataclass"""

from dataclasses import dataclass, field
from datetime import date
from decimal import Decimal

CATEGORIES = (
    "food",
    "transport",
    "bills",
    "shopping",
    "health",
    "entertainment",
    "other",
)


class Account:
    """บัญชีเงินฝากพื้นฐาน"""

    bank_name = "Python Bank"  # Class Attribute: ใช้ร่วมกันทุก Object

    def __init__(self, owner: str, balance: Decimal = Decimal("0")) -> None:
        self.owner = owner  # Instance Attribute: ของใครของมัน
        self._balance = balance  # _ นำหน้า = ใช้ภายใน Class

    @property
    def balance(self) -> Decimal:
        """ยอดเงินแบบอ่านอย่างเดียว"""
        return self._balance

    def deposit(self, amount: Decimal) -> None:
        if amount <= 0:
            raise ValueError("จำนวนเงินฝากต้องมากกว่า 0")
        self._balance += amount

    def withdraw(self, amount: Decimal) -> None:
        if amount > self._balance:
            raise ValueError(f"ยอดเงินไม่พอ (มี {self._balance:,.2f} บาท)")
        self._balance -= amount

    def __str__(self) -> str:  # สำหรับผู้ใช้ทั่วไป
        return f"บัญชีของ {self.owner}: {self._balance:,.2f} บาท"

    def __repr__(self) -> str:  # สำหรับนักพัฒนา
        return f"Account(owner={self.owner!r}, balance={self._balance!r})"


class SavingsAccount(Account):
    """บัญชีออมทรัพย์: สืบทอดจาก Account แล้วเพิ่มดอกเบี้ย"""

    def __init__(self, owner: str, balance: Decimal, rate: Decimal) -> None:
        super().__init__(owner, balance)  # ให้ Class แม่ตั้งค่า owner และ _balance
        self.rate = rate

    def add_interest(self) -> Decimal:
        interest = (self._balance * self.rate).quantize(Decimal("0.01"))
        self.deposit(interest)
        return interest

    def __str__(self) -> str:  # Override: เขียนทับ Method ของ Class แม่
        return f"{super().__str__()} (ออมทรัพย์ {self.rate:.2%})"


@dataclass
class Expense:
    """รายการค่าใช้จ่าย 1 รายการ (Model เดียวกับ Mini Project)"""

    id: int
    date: date
    category: str
    amount: Decimal
    note: str = ""

    def __post_init__(self) -> None:
        # ตรวจข้อมูลทันทีหลัง __init__ ที่ Dataclass สร้างให้
        if self.category not in CATEGORIES:
            raise ValueError(f"ไม่รู้จักหมวด {self.category!r}")
        if self.amount <= 0:
            raise ValueError("amount ต้องมากกว่า 0")

    @classmethod
    def from_row(cls, row: dict[str, str]) -> "Expense":
        """สร้าง Expense จาก 1 แถวของ csv.DictReader (Alternate Constructor)"""
        return cls(
            id=int(row["id"]),
            date=date.fromisoformat(row["date"]),
            category=row["category"],
            amount=Decimal(row["amount"]),
            note=row["note"],
        )


@dataclass(frozen=True, order=True)
class Rate:
    """อัตราแลกเปลี่ยน: แก้ไขไม่ได้ (frozen) และเปรียบเทียบมากน้อยได้ (order)"""

    value: Decimal
    currency: str


@dataclass
class Budget:
    """งบประมาณรายเดือน: Composition คือ "มี" Expense อยู่ข้างใน"""

    month: str
    limit: Decimal
    expenses: list[Expense] = field(default_factory=list)  # list ใหม่ทุก Object

    def spent(self) -> Decimal:
        return sum((e.amount for e in self.expenses), Decimal("0"))

    def remaining(self) -> Decimal:
        return self.limit - self.spent()


def main() -> None:
    print("=== Class และ Object ===")
    acc = Account("สมชาย", Decimal("1000"))
    acc.deposit(Decimal("250.50"))
    acc.withdraw(Decimal("100"))
    print(acc)
    print(repr(acc))
    print("ธนาคาร:", acc.bank_name, "| ยอด (property):", acc.balance)
    try:
        acc.withdraw(Decimal("5000"))
    except ValueError as e:
        print("ถอนไม่ได้:", e)

    print("=== Inheritance ===")
    sav = SavingsAccount("สมศรี", Decimal("20000"), Decimal("0.0125"))
    print("ดอกเบี้ย:", sav.add_interest())
    print(sav)
    print("เป็น Account ด้วยไหม:", isinstance(sav, Account))

    print("=== Dataclass ===")
    row = {"id": "3", "date": "2026-10-01", "category": "bills"}
    row |= {"amount": "1250.50", "note": "ค่าไฟฟ้า"}  # รวม dict 2 ก้อน
    e1 = Expense.from_row(row)
    e2 = Expense.from_row(row)
    print(repr(e1))
    print("e1 == e2:", e1 == e2, "| เป็น Object เดียวกันไหม:", e1 is e2)
    e4 = Expense(4, date(2026, 10, 2), "food", Decimal("65.00"), "กาแฟเย็น")
    e5 = Expense(
        id=5, date=date(2026, 10, 3), category="shopping", amount=Decimal("299")
    )
    by_amount = sorted([e1, e4, e5], key=lambda e: e.amount)
    print("เรียงตาม amount:", [f"{e.amount:,.2f}" for e in by_amount])
    try:
        Expense(9, date(2026, 10, 19), "coffee", Decimal("10"))
    except ValueError as e:
        print("สร้างไม่ได้:", e)

    print("=== frozen / order / composition ===")
    rates = [Rate(Decimal("4.62"), "JPY"), Rate(Decimal("0.0305"), "USD")]
    print("Rate ต่ำสุด:", min(rates))
    budget = Budget("2026-10", Decimal("3000"))
    budget.expenses.extend([e1, e4, e5])
    print(f"ใช้ไป {budget.spent():,.2f} | เหลือ {budget.remaining():,.2f} บาท")
    print("Budget ใหม่มี expenses:", Budget("2026-11", Decimal("1000")).expenses)


if __name__ == "__main__":
    main()

Best Practice
  • เริ่มจาก Dataclass สำหรับข้อมูล และเพิ่ม Method เมื่อมีกฎที่ผูกกับข้อมูลนั้นจริง ไม่ต้องสร้าง Class ให้ทุกอย่าง Function ธรรมดาก็ดีพอในหลายกรณี
  • ตรวจความถูกต้องของข้อมูลใน __post_init__ หรือ Setter เพื่อให้ "Object ที่สร้างได้ถูกต้องเสมอ" โค้ดส่วนอื่นจะไม่ต้องตรวจซ้ำ
  • ใช้ Inheritance ไม่เกิน 1–2 ชั้น และเลือก Composition ก่อนเมื่อไม่แน่ใจ ลำดับชั้นที่ลึกทำให้แก้ไขยาก
  • เก็บเงินเป็น Decimal สร้างจาก str (Decimal("89.50")) ไม่ใช่จาก float และเขียน __repr__ ที่ช่วยดีบักได้

  • Iterator: ทุกครั้งที่เขียน for x in data: Python เรียก iter(data) เพื่อขอ Iterator แล้วเรียก next() ซ้ำ ๆ จนเจอ StopIteration จึงหยุด นี่คือ Iteration Protocol ที่ list, str, dict, file และ range ใช้ร่วมกัน
  • Generator: Function ที่มี yield แทน return ทุกครั้งที่ถูก next() จะทำงานจนถึง yield ส่งค่าออกมาแล้วหยุดรอ ค่าถูกสร้างทีละตัวเมื่อมีคนขอ (Lazy Evaluation) จึงใช้หน่วยความจำคงที่แม้ข้อมูลมีล้านบรรทัด Generator Expression (x for x in ...) คือแบบย่อในวงเล็บกลม และ yield from ส่งต่อทุกค่าจาก Iterable อื่น ข้อควรจำ: Generator ใช้ได้ รอบเดียว
  • Decorator: ใน Python Function เป็น Object ส่งเป็น Argument และคืนจาก Function อื่นได้ Decorator คือ Function ที่รับ Function แล้วคืน Function ใหม่ที่ห่อของเดิมไว้ (ใช้ Closure คือ Function ข้างในจำตัวแปรของ Function ข้างนอกได้) เขียน @timer เหนือ def มีความหมายเท่ากับ func = timer(func) ใช้เพิ่มพฤติกรรมร่วม เช่น วัดเวลา Log ลองใหม่ ตรวจสิทธิ์ หรือ Cache โดยไม่แก้โค้ดของ Function เดิม
  • Context Manager: Object ที่ใช้กับ with มี __enter__ (ทำตอนเข้า) และ __exit__ (ทำตอนออก แม้เกิด Error) เราใช้มาแล้วกับ with open(...) สร้างเองได้ทั้งแบบ Class และแบบ @contextlib.contextmanager ใช้กับทุกอย่างที่ "เปิดแล้วต้องปิด" เช่น ไฟล์ การเชื่อมต่อฐานข้อมูล Lock หรือการจับเวลา

"""Iterator, Generator, Decorator และ Context Manager"""

import functools
import sys
import time
from collections.abc import Callable, Iterator
from contextlib import contextmanager
from pathlib import Path
from typing import Any

CSV_PATH = Path(__file__).parent / "data" / "expenses.csv"


# ---------- Generator ----------
def read_lines(path: Path) -> Iterator[str]:
    """อ่านไฟล์ทีละบรรทัดแบบ lazy คืนเฉพาะบรรทัดที่ไม่ว่าง"""
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                yield line  # หยุดตรงนี้ ส่งค่าออกไป แล้วรอถูกเรียกครั้งถัดไป


def countdown(n: int) -> Iterator[int]:
    """Generator ง่าย ๆ ที่นับถอยหลัง"""
    while n > 0:
        yield n
        n -= 1


def all_numbers() -> Iterator[int]:
    """yield from ส่งต่อทุกค่าจาก Generator อื่น"""
    yield from countdown(2)
    yield from [10, 20]


# ---------- Decorator ----------
def timer(func: Callable[..., Any]) -> Callable[..., Any]:
    """วัดเวลาที่ Function ใช้"""

    @functools.wraps(func)  # รักษาชื่อและ docstring ของ func เดิม
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed_ms = (time.perf_counter() - start) * 1000
        label = "น้อยกว่า 100 ms" if elapsed_ms < 100 else f"{elapsed_ms:.1f} ms"
        print(f"[timer] {func.__name__} ใช้เวลา {label}")
        return result  # อย่าลืมคืนผลลัพธ์

    return wrapper


def log_call(func: Callable[..., Any]) -> Callable[..., Any]:
    """พิมพ์ Argument และผลลัพธ์ทุกครั้งที่ถูกเรียก"""

    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        result = func(*args, **kwargs)
        print(f"[log] {func.__name__}{args} kwargs={kwargs} -> {result!r}")
        return result

    return wrapper


def retry(times: int = 3) -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    """Decorator ที่รับ Argument: ลองใหม่ได้สูงสุด times ครั้ง"""

    def decorator(func: Callable[..., Any]) -> Callable[..., Any]:
        @functools.wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except ConnectionError as e:
                    print(f"[retry] ครั้งที่ {attempt} ล้มเหลว: {e}")
            raise ConnectionError(f"ลองครบ {times} ครั้งแล้วยังไม่สำเร็จ")

        return wrapper

    return decorator


calls = {"n": 0}


@retry(times=3)
def flaky_fetch() -> str:
    """จำลองการเรียก API ที่ล้มเหลว 2 ครั้งแรก"""
    calls["n"] += 1
    if calls["n"] < 3:
        raise ConnectionError("server ไม่ตอบ")
    return "ได้ข้อมูลแล้ว"


@log_call
def add_vat(amount: float, rate: float = 0.07) -> float:
    return round(amount * (1 + rate), 2)


@functools.cache
def fib(n: int) -> int:
    """Fibonacci แบบ Recursive ที่จำผลลัพธ์ไว้ (Memoization)"""
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)


@timer
def sum_october(path: Path) -> float:
    """Pipeline ของ Generator: ไม่มีการสร้าง list ระหว่างทาง"""
    lines = read_lines(path)
    rows = (line.split(",") for line in lines)
    october = (row for row in rows if row[1].startswith("2026-10"))
    return sum(float(row[3]) for row in october)


# ---------- Context Manager ----------
class Section:
    """Context Manager แบบ Class"""

    def __init__(self, name: str) -> None:
        self.name = name

    def __enter__(self) -> "Section":
        print(f"-> เข้า {self.name}")
        return self

    def __exit__(self, exc_type: Any, exc: Any, tb: Any) -> bool:
        print(f"<- ออก {self.name} (มี Error: {exc_type is not None})")
        return False  # False = ไม่กลืน Error ปล่อยให้ไหลต่อ


@contextmanager
def section(name: str) -> Iterator[None]:
    """Context Manager แบบ Generator"""
    print(f"-> เข้า {name}")
    try:
        yield
    finally:
        print(f"<- ออก {name} (cleanup ทำงานเสมอ)")


def main() -> None:
    print("=== Iterator Protocol ===")
    it = iter(["ชา", "กาแฟ"])
    print(next(it), next(it))
    try:
        next(it)
    except StopIteration:
        print("หมดแล้ว: StopIteration")

    print("=== Generator ===")
    gen = countdown(3)
    print(type(gen).__name__, list(gen), "| ใช้ซ้ำ:", list(gen))
    print("yield from:", list(all_numbers()))
    print("list 1 ล้านตัว:", sys.getsizeof(list(range(1_000_000))), "bytes")
    print("generator:", sys.getsizeof(x for x in range(1_000_000)), "bytes")
    print("ยอดเดือนตุลาคม:", sum_october(CSV_PATH))

    print("=== Decorator ===")
    add_vat(100)
    add_vat(250, rate=0.1)
    print(flaky_fetch())
    print("fib(80) =", fib(80))
    print("ชื่อ Function หลังใส่ Decorator:", sum_october.__name__)

    print("=== Context Manager ===")
    with Section("งานปกติ"):
        print("   ทำงานใน with")
    try:
        with section("งานที่พัง"):
            raise ValueError("ข้อมูลผิด")
    except ValueError as e:
        print("จับ Error ได้นอก with:", e)


if __name__ == "__main__":
    main()

Best Practice
  • ใช้ Generator กับข้อมูลที่ใหญ่หรือไม่รู้ขนาด เช่น อ่าน Log หรือ CSV ขนาดใหญ่ และส่งต่อเป็น Pipeline แทนการสร้าง list ทุกขั้น
  • Decorator ทุกตัวต้องมี @functools.wraps, รับ *args, **kwargs และคืนผลลัพธ์ ใช้กับเรื่องที่ตัดขวางหลาย Function (Log, Retry, Cache, Auth) เท่านั้น
  • ทรัพยากรที่ต้องปิดหรือคืน (ไฟล์ Connection Lock) ให้ใช้ with เสมอ และเขียน Context Manager ด้วย @contextmanager + try/finally ซึ่งสั้นกว่าแบบ Class
  • ใช้ functools.cache เฉพาะกับ Function ที่ผลลัพธ์ขึ้นกับ Argument อย่างเดียว (Pure Function) ห้ามใช้กับ Function ที่อ่านไฟล์หรือเวลาปัจจุบัน

  • pytest: เครื่องมือรัน Test ที่นิยมที่สุดของ Python ใช้ assert ธรรมดาเป็นตัวตรวจ ถ้าเงื่อนไขหลัง assert เป็น False Test นั้นจะ FAILED และ pytest จะแสดงค่าจริงเทียบกับค่าที่คาดหวังให้เห็นชัด ๆ pytest หา Test เองตามกฎการตั้งชื่อ (Discovery): ไฟล์ต้องชื่อ test_*.py หรือ *_test.py และ Function ต้องขึ้นต้นด้วย test_ เครื่องมือที่ใช้บ่อยคือ pytest.raises (ตรวจว่าเกิด Exception ตามที่ควร) @pytest.mark.parametrize (รัน Test เดียวกับข้อมูลหลายชุด) pytest.approx (เทียบเลขทศนิยมแบบยอมคลาดเคลื่อนเล็กน้อย) และ Fixture เช่น tmp_path ที่สร้างโฟลเดอร์ชั่วคราวให้แต่ละ Test
  • ruff: เครื่องมือตัวเดียวที่เป็นทั้ง Linter (ตรวจหาโค้ดที่น่าจะผิดหรือไม่เป็นมาตรฐาน เช่น import แล้วไม่ใช้ หรือใช้ list เป็นค่า Default) และ Formatter (จัดรูปแบบโค้ดให้เหมือนกันทั้งทีม เช่น เว้นวรรคหลังจุลภาค) คำสั่งหลักคือ ruff check, ruff check --fix, ruff format และ ruff format --check เราเลือกกลุ่มกฎได้ใน pyproject.toml เช่น E (รูปแบบโค้ดตาม PEP 8) F (Error ที่พบบ่อย) I (เรียง import) B (Bug ที่พบบ่อย) และ UP (ใช้ Syntax ของ Python รุ่นใหม่)
  • Big-O: วิธีบอกว่าเวลาทำงานของอัลกอริทึม "โตขึ้นแค่ไหน" เมื่อข้อมูลมากขึ้น ไม่ได้บอกเป็นวินาที แต่บอกแนวโน้ม O(1) คือเวลาคงที่ไม่ว่าข้อมูลมากแค่ไหน (ค้นหาใน dict หรือ set) O(log n) คือข้อมูลเพิ่มสองเท่าแต่ใช้เพิ่มแค่หนึ่งขั้น (Binary Search ในข้อมูลที่เรียงแล้ว) O(n) คือโตตามข้อมูล (ค้นหาใน list ทีละตัว) O(n log n) คือการเรียงข้อมูลด้วย sorted() และ O(n²) คือ Loop ซ้อน Loop ที่ข้อมูลเพิ่ม 10 เท่าแต่ช้าลง 100 เท่า เราวัดเวลาจริงด้วยโมดูล timeit ที่รันโค้ดซ้ำหลายรอบแล้วรวมเวลาให้

ใช้เมื่อไร: เขียน Test ทุกครั้งที่เขียน Function ที่มีตรรกะ (Logic) โดยเฉพาะ Function ที่คำนวณเงิน ตรวจ Input หรืออ่านเขียนไฟล์ รัน ruff check และ ruff format ก่อน git commit ทุกครั้ง และคิดเรื่อง Big-O เมื่อข้อมูลเริ่มมีหลักพันแถวขึ้นไป หรือเมื่อเห็น Loop ซ้อน Loop ส่วน Mini Project ของหัวข้อนี้ต้องมี Test อย่างน้อย 12 ตัวและผ่าน ruff ด้วย ทุกอย่างในแนวคิดนี้จึงจะได้ใช้จริงทันที

"""อัลกอริทึมค้นหาพื้นฐาน สำหรับฝึกเขียน Test และเปรียบเทียบ Big-O"""


def linear_search(items: list[int], target: int) -> int:
    """ไล่หาทีละตัวจากซ้ายไปขวา คืน index ที่เจอ หรือ -1 ถ้าไม่เจอ: O(n)"""
    for index, value in enumerate(items):
        if value == target:
            return index
    return -1


def is_sorted(items: list[int]) -> bool:
    """ตรวจว่าข้อมูลเรียงจากน้อยไปมากหรือไม่"""
    return all(items[i] <= items[i + 1] for i in range(len(items) - 1))


def binary_search(items: list[int], target: int) -> int:
    """ค้นหาแบบแบ่งครึ่งในข้อมูลที่เรียงแล้ว คืน index หรือ -1: O(log n)"""
    if not is_sorted(items):
        raise ValueError("binary_search ต้องใช้กับข้อมูลที่เรียงแล้วเท่านั้น")
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2  # ตำแหน่งตรงกลางของช่วงที่เหลือ
        if items[mid] == target:
            return mid
        if items[mid] < target:
            low = mid + 1  # เป้าหมายอยู่ครึ่งขวา
        else:
            high = mid - 1  # เป้าหมายอยู่ครึ่งซ้าย
    return -1


def find_common_slow(a: list[int], b: list[int]) -> list[int]:
    """หาค่าที่อยู่ทั้งสอง list ด้วย Loop ซ้อน Loop: O(n * m)"""
    result = []
    for x in a:
        for y in b:  # ทุกตัวของ a ต้องไล่ดู b ทั้งหมด
            if x == y and x not in result:
                result.append(x)
    return sorted(result)


def find_common_fast(a: list[int], b: list[int]) -> list[int]:
    """หาค่าที่อยู่ทั้งสอง list ด้วย set: O(n + m)"""
    return sorted(set(a) & set(b))
