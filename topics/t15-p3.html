Fill-in-the-blank

เติมคำหรือโค้ดที่หายไปในช่อง _____ ให้ถูกต้อง ทุกข้อใช้ tsconfig.json แบบ strict ของหัวข้อนี้

  1. ง่าย

    "_____": true
  }
}
  2. ง่าย

    ต้องการให้ tsc ตรวจ Type อย่างเดียว โดยไม่สร้างไฟล์ .js ลงในโฟลเดอร์ dist/ (เหมาะกับการรันใน CI หรือ npm script ชื่อ typecheck) ให้ใช้คำสั่ง

    npx tsc _____
  3. ง่าย

    โปรเจกต์เปิด noUncheckedIndexedAccess ไว้ จากโค้ดด้านล่าง Type ของตัวแปร first คือ number | _____

// ดึง Type ของสมาชิกทุกตัวใน Array ออกมาเป็น Union
type Status = (typeof STATUSES)[_____];

    เขียน User-defined Type Guard เพื่อบอก TypeScript ว่า ถ้าฟังก์ชันคืน true แปลว่า v เป็น Task ให้เติม Keyword ที่หายไป

// ฟังก์ชันตรวจข้อมูล unknown ว่าเป็น Task หรือไม่
function isTask(v: unknown): v _____ Task {

}

    เขียน Conditional Type ที่ "แกะ" Type ข้างใน Promise ออกมา เช่น UnwrapPromise<Promise<number>> ได้ number ส่วน Type ที่ไม่ใช่ Promise ให้คืนตัวเดิม ให้เติม Keyword ที่ใช้ประกาศตัวแปร Type ระหว่างการเทียบ

    // ถ้า T เป็น Promise ของอะไรสักอย่าง ให้จับสิ่งนั้นไว้ในชื่อ U แล้วคืน U
type UnwrapPromise<T> = T extends Promise<_____ U> ? U : T;
  9. ยาก

    สร้าง Mapped Type ชื่อ Getters<T> ที่เปลี่ยนชื่อ Key ทุกตัวเป็น get ตามด้วยชื่อเดิมที่ขึ้นต้นด้วยตัวพิมพ์ใหญ่ เช่น name กลายเป็น getName ให้เติม Intrinsic String Type ที่ใช้แปลงตัวอักษรแรกเป็นตัวพิมพ์ใหญ่

    type Getters<T> = {
  // Key Remapping ด้วย as และ Template Literal Type
  [K in keyof T as `get${_____<string & K>}`]: () => T[K];
};

// ผลลัพธ์ที่ต้องการ: { getName: () => string; getAge: () => number }
type G = Getters<{ name: string; age: number }>;

เลือกคำตอบที่ถูกที่สุดเพียงข้อเดียว ทุกข้อสมมติว่าโปรเจกต์ใช้ TypeScript 7.0.2 กับ tsconfig.json แบบ strict ของหัวข้อนี้ และรันด้วย Node.js LTS (24 หรือ 26) คำถามเรียงตามแนวคิดใน Part 2 ตั้งแต่แนวคิดที่ 1 ถึง 12

    ฟังก์ชันคำนวณค่าส่งด้านล่างระบุ Return Type เป็น number ไว้ เมื่อรัน npx tsc จะได้ผลอย่างไร

    2. ไม่มี Error เพราะ TypeScript รู้ว่ายอดซื้อต้องมากกว่า 0 เสมอ
    3. ได้ error TS2554: Expected 1 arguments, but got 0.
    4. ไม่มี Error ตอน Compile แต่ตอนรัน Node จะ throw Error เพราะฟังก์ชันไม่มี return
  5. กลาง

    ทำไมหัวข้อนี้จึงแนะนำให้ใช้ Union ของ Literal Types เช่น type Priority = "low" | "medium" | "high" แทน enum Priority { Low, Medium, High }

    1. เพราะ enum ถูกลบออกจาก TypeScript 7 แล้ว ทุกโปรเจกต์จึงใช้ไม่ได้อีก
    2. เพราะ enum ทำงานช้ากว่า Union มากตอนรัน
    3. เพราะ Union ของ Literal Types ใช้กับ switch ไม่ได้ จึงบังคับให้เขียนโค้ดสั้นลง
    4. เพราะ enum สร้างโค้ด JavaScript จริงขึ้นมา จึงไม่ใช่ Syntax ที่ลบทิ้งได้ เมื่อเปิด erasableSyntaxOnly จะได้ error TS1294 และ Type Stripping ของ Node ก็รันไม่ได้
  6. กลาง

    ทีมเพิ่มสมาชิกใหม่ { kind: "archive"; id: string } เข้าไปใน Command แต่ลืมเพิ่ม case "archive" ใน switch เมื่อรัน npx tsc จะเกิดอะไรขึ้น

    type Command =
  | { kind: "add"; title: string }
  | { kind: "done"; id: string }
  | { kind: "archive"; id: string }; // เพิ่มใหม่

function assertNever(x: never): never {
  throw new Error("ไม่ได้จัดการ: " + JSON.stringify(x));
}

function describe(cmd: Command): string {
  switch (cmd.kind) {
    case "add":
      return "เพิ่ม " + cmd.title;
    case "done":
      return "ปิดงาน " + cmd.id;
    default:
      return assertNever(cmd);
  }
}
    1. Compile ผ่าน แต่ตอนรันจะ throw Error เฉพาะเมื่อมีคำสั่ง archive เข้ามาจริง
    2. ได้ error TS2345: Argument of type '{ kind: "archive"; id: string; }' is not assignable to parameter of type 'never'. ที่บรรทัด assertNever(cmd)
    3. ได้ Error ที่บรรทัดประกาศ type Command ว่ามีสมาชิกที่ไม่ได้ใช้
    4. TypeScript เพิ่ม case "archive" ให้อัตโนมัติในไฟล์ .js ที่ได้
  7. กลาง

    จากโค้ดด้านล่าง ข้อใดอธิบายความต่างระหว่าง private ของ TypeScript กับ #private ของ JavaScript ได้ถูกต้อง

    class AccountA {
  private balance = 1000; // private ของ TypeScript
}
class AccountB {
  #balance = 1000; // private ของ JavaScript
  get balance(): number {
    return this.#balance;
  }
}
const a = new AccountA();
const b = new AccountB();
console.log((a as any).balance);
console.log((b as any)["#balance"]);
    1. private ตรวจแค่ตอน Compile ตอนรันค่ายังเข้าถึงได้ จึงพิมพ์ 1000 ส่วน #balance เป็นของจริงตอนรัน การอ่านด้วย ["#balance"] จึงได้ undefined
    2. ทั้งสองแบบปลอดภัยเท่ากันตอนรัน โค้ดนี้จึงพิมพ์ undefined ทั้งสองบรรทัด
    3. private ปลอดภัยกว่า เพราะ tsc เข้ารหัสค่าใน dist/ ให้ ส่วน #balance อ่านได้ปกติจึงพิมพ์ 1000
    4. #balance ใช้ไม่ได้เมื่อเปิด erasableSyntaxOnly เพราะไม่ใช่ Syntax ที่ลบทิ้งได้
  8. กลาง

// อ่านค่า property ตามชื่อ key แบบ Type-safe
function getProp<T, K extends keyof T>(obj: T, key: K): T[K] {

}

const task: Task = { id: "T-001", title: "ติดตั้ง TypeScript 7", priority: "high" };

    2. keyof Task

ข้อ 1

คำตอบ: strict

"strict": true เปิดกลุ่มการตรวจแบบเข้มงวดทั้งชุดพร้อมกัน เช่น noImplicitAny (ห้ามมี Parameter ที่ไม่รู้ Type), strictNullChecks (แยก null/undefined ออกจาก Type อื่น), strictFunctionTypes และ useUnknownInCatchVariables โปรเจกต์ใหม่ทุกโปรเจกต์ควรเปิดตั้งแต่วันแรก เพราะการมาเปิดทีหลังในโปรเจกต์ใหญ่จะเจอ Error หลายร้อยจุดพร้อมกัน

ส่วนตัวเลือกอย่าง noUncheckedIndexedAccess และ exactOptionalPropertyTypes ไม่ได้อยู่ในชุด strict ต้องเปิดแยกเอง ซึ่ง tsconfig.json ของหัวข้อนี้เปิดไว้แล้ว

ข้อ 2

คำตอบ: --noEmit

npx tsc --noEmit ทำเฉพาะขั้น Type Check แล้วจบ ไม่เขียนไฟล์ .js หรือ .js.map ลง dist/ เลย ถ้ามี Error จะคืน Exit Code ที่ไม่ใช่ 0 ทำให้ CI รู้ว่าต้องหยุด ใน package.json ของ ts-lab จึงมี script "typecheck": "tsc --noEmit" ไว้รันก่อน Commit หรือใน GitHub Actions

ข้อ 3

คำตอบ: undefined (Type เต็มคือ number | undefined)

ตอนเขียนโค้ด TypeScript ไม่รู้ว่า Array มีสมาชิกกี่ตัว การอ่าน prices[0] อาจได้ undefined ถ้า Array ว่าง เมื่อเปิด noUncheckedIndexedAccess Compiler จะบังคับให้เราตรวจก่อนใช้ เช่น if (first !== undefined) { ... } หรือใช้ first ?? 0 ถ้าเอา first ไปคำนวณตรง ๆ จะได้ Error TS18048: 'first' is possibly 'undefined'.

ข้อ 4

คำตอบ: number

typeof STATUSES คือ Type ของ Array readonly ["todo", "doing", "done"] การเขียน [number] เป็น Indexed Access ที่หมายถึง "Type ของสมาชิกที่อ่านด้วย index ใดก็ได้ที่เป็นตัวเลข" จึงได้ Union ของสมาชิกทุกตัว คือ "todo" | "doing" | "done" ข้อดีคือมีรายการค่าอยู่ที่เดียว ใช้ได้ทั้งตอนรัน (วนลูป แสดงตัวเลือก) และตอนตรวจ Type

ถ้าลืม as const Type ของ Array จะกว้างเป็น string[] และ Status จะกลายเป็น string ธรรมดา ซึ่งไม่ช่วยจับค่าที่สะกดผิด

ข้อ 5

คำตอบ: is (Return Type เต็มคือ v is Task)

Return Type แบบ v is Task เรียกว่า Type Predicate บอก Compiler ว่า ถ้าฟังก์ชันคืน true ให้ถือว่า v เป็น Task ใน Block นั้น เช่น if (isTask(data)) { data.title } ใช้ได้ทันที ถ้าเขียนเป็น boolean ธรรมดา Compiler จะไม่ Narrow ให้

  • D ผิดเพราะ T ในแต่ละรอบคือ string หรือ number ไม่ใช่ unknown ผลจึงเป็น T[] ของสมาชิกนั้น ไม่ใช่ unknown[]

// โจทย์ที่ 1: ใบเสร็จร้านกาแฟแบบ Type-safe

// หมวดสินค้าเป็น Union ของ Literal Types (ไม่ใช้ enum)
type Category = "coffee" | "tea" | "bakery";

// ข้อมูลเมนู 1 รายการ: code เป็น readonly เพราะห้ามเปลี่ยนรหัสสินค้า
type MenuItem = {
  readonly code: string;
  name: string;
  price: number;
  category: Category;
};

// รายการสั่ง 1 บรรทัดเป็น Named Tuple: [รหัสสินค้า, จำนวน]
type OrderLine = [code: string, qty: number];

// ผลการคำนวณใบเสร็จ
type Receipt = {
  lines: { name: string; qty: number; amount: number }[];
  unknownCodes: string[];
  subtotal: number;
  discount: number;
  total: number;
};

const MENU: readonly MenuItem[] = [
  { code: "C01", name: "Americano เย็น", price: 65, category: "coffee" },
  { code: "C02", name: "Latte ร้อน", price: 70, category: "coffee" },
  { code: "T01", name: "ชาไทยเย็น", price: 55, category: "tea" },
  { code: "B01", name: "ครัวซองต์เนยสด", price: 79, category: "bakery" },
];

// find() คืน MenuItem | undefined เสมอ ผู้เรียกต้องจัดการกรณีไม่เจอ
function findItem(code: string): MenuItem | undefined {
  return MENU.find((item) => item.code === code);
}

// แปลงตัวเลขเป็นรูปแบบเงินบาท เช่น 1,234.00 บาท
function formatBaht(amount: number): string {
  return (
    amount.toLocaleString("th-TH", {
      minimumFractionDigits: 2,
      maximumFractionDigits: 2,
    }) + " บาท"
  );
}

// discountPercent เป็น Optional Parameter: ไม่ส่งมาก็ได้
function calcReceipt(
  order: readonly OrderLine[],
  discountPercent?: number,
): Receipt {
  const lines: Receipt["lines"] = [];
  const unknownCodes: string[] = [];

  for (const [code, qty] of order) {
    const item = findItem(code);
    if (item === undefined) {
      // Narrowing: หลังบรรทัดนี้ TypeScript รู้ว่า item ไม่ใช่ undefined
      unknownCodes.push(code);
      continue;
    }
    lines.push({ name: item.name, qty, amount: item.price * qty });
  }

  const subtotal = lines.reduce((sum, line) => sum + line.amount, 0);
  const discount =
    discountPercent === undefined
      ? 0
      : Math.round(subtotal * discountPercent) / 100;
  return { lines, unknownCodes, subtotal, discount, total: subtotal - discount };
}

function printReceipt(receipt: Receipt): void {
  console.log("===== ร้านกาแฟบ้านสมชาย =====");
  for (const line of receipt.lines) {
    console.log(
      `${line.name.padEnd(16)} x${line.qty}  ${formatBaht(line.amount)}`,
    );
  }
  for (const code of receipt.unknownCodes) {
    console.log(`(ข้าม) ไม่พบรหัสสินค้า ${code}`);
  }
  console.log(`ยอดก่อนส่วนลด : ${formatBaht(receipt.subtotal)}`);
  console.log(`ส่วนลด        : ${formatBaht(receipt.discount)}`);
  console.log(`ยอดสุทธิ      : ${formatBaht(receipt.total)}`);
}

// โจทย์ที่ 2: แปลง Webhook Events ของร้านออนไลน์ให้เป็นข้อความแจ้งเตือน
import { readFile } from "node:fs/promises";

// ---------- 1) Types ----------
const PAY_METHODS = ["promptpay", "card", "cash"] as const;
type PayMethod = (typeof PAY_METHODS)[number];

// Discriminated Union: ทุกสมาชิกมีฟิลด์ type เป็น Literal ที่ไม่ซ้ำกัน
type OrderEvent =
  | { type: "order.created"; orderId: string; customer: string; total: number }
  | { type: "order.paid"; orderId: string; method: PayMethod }
  | { type: "order.shipped"; orderId: string; trackingNo: string }
  | { type: "order.cancelled"; orderId: string; reason: string };

type EventType = OrderEvent["type"];

// ผลการตรวจ 1 รายการ: ผ่าน หรือ ไม่ผ่านพร้อมเหตุผล
type Checked =
  | { ok: true; event: OrderEvent }
  | { ok: false; index: number; reason: string };

// ---------- 2) Type Guards สำหรับข้อมูล unknown ----------
function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

function isPayMethod(v: unknown): v is PayMethod {
  return typeof v === "string" && (PAY_METHODS as readonly string[]).includes(v);
}

// ตรวจ 1 รายการ แล้วคืน Checked (ไม่ throw)
function checkEvent(raw: unknown, index: number): Checked {
  const fail = (reason: string): Checked => ({ ok: false, index, reason });
  if (!isRecord(raw)) return fail("ไม่ใช่ object");
  const { type, orderId } = raw;
  if (typeof orderId !== "string") return fail("orderId ต้องเป็น string");

  switch (type) {
    case "order.created":
      if (typeof raw.customer !== "string") return fail("customer ต้องเป็น string");
      if (typeof raw.total !== "number") return fail("total ต้องเป็น number");
      return { ok: true, event: { type, orderId, customer: raw.customer, total: raw.total } };
    case "order.paid":
      if (!isPayMethod(raw.method)) return fail(`method ไม่รองรับ: ${String(raw.method)}`);
      return { ok: true, event: { type, orderId, method: raw.method } };
    case "order.shipped":
      if (typeof raw.trackingNo !== "string") return fail("trackingNo ต้องเป็น string");
      return { ok: true, event: { type, orderId, trackingNo: raw.trackingNo } };
    case "order.cancelled":
      if (typeof raw.reason !== "string") return fail("reason ต้องเป็น string");
      return { ok: true, event: { type, orderId, reason: raw.reason } };
    default:
      return fail(`ไม่รู้จัก type: ${String(type)}`);
  }
}

// ---------- 3) Exhaustive switch ----------
function assertNever(x: never): never {
  throw new Error("มี Event ที่ยังไม่ได้จัดการ: " + JSON.stringify(x));
}

function toMessage(e: OrderEvent): string {
  switch (e.type) {
    case "order.created":
      return `[${e.orderId}] ${e.customer} สั่งซื้อ ยอด ${e.total.toLocaleString("th-TH")} บาท`;
    case "order.paid":
      return `[${e.orderId}] ชำระเงินแล้วผ่าน ${e.method}`;
    case "order.shipped":
      return `[${e.orderId}] จัดส่งแล้ว เลขพัสดุ ${e.trackingNo}`;
    case "order.cancelled":
      return `[${e.orderId}] ถูกยกเลิก: ${e.reason}`;
    default:
      return assertNever(e);
  }
}

// ---------- 4) Generic helper ----------
// นับจำนวนตาม key ที่ได้จาก callback โดย K ต้องเป็น string
function countBy<T, K extends string>(
  items: readonly T[],
  keys: readonly K[],
  keyOf: (item: T) => K,
): Record<K, number> {
  const result = {} as Record<K, number>;
  for (const k of keys) result[k] = 0;
  for (const item of items) result[keyOf(item)] += 1;
  return result;
}

const EVENT_TYPES: readonly EventType[] = [
  "order.created",
  "order.paid",
  "order.shipped",
  "order.cancelled",
];

// ---------- 5) main ----------
const fileUrl = new URL("../data/events.json", import.meta.url);
const parsed: unknown = JSON.parse(await readFile(fileUrl, "utf8"));

if (!Array.isArray(parsed)) {
  console.error("ไฟล์ต้องเป็น JSON array");
  process.exitCode = 1;
} else {
  const checked = parsed.map((raw: unknown, i) => checkEvent(raw, i));
  const events: OrderEvent[] = [];
  console.log("--- ข้อความแจ้งเตือน ---");
  for (const c of checked) {
    if (c.ok) {
      events.push(c.event);
      console.log(toMessage(c.event));
    }
  }
  console.log("--- รายการที่ถูกปฏิเสธ ---");
  for (const c of checked) {
    if (!c.ok) console.log(`#${c.index}: ${c.reason}`);
  }
  console.log("--- สรุปตามประเภท ---");
  console.log(countBy(events, EVENT_TYPES, (e) => e.type));
}

// Client สำหรับเรียก Inventory API แบบ Type-safe
import { z } from "zod";
import type { Result } from "./result.ts";
import { CATEGORIES } from "./schemas.ts";
import type { Category, Product } from "./schemas.ts";

// Generic: T ถูกอนุมานจาก Schema ที่ส่งเข้ามา
export async function getJson<T>(
  url: string,
  schema: z.ZodType<T>,
): Promise<Result<T>> {
  let res: Response;
  try {
    res = await fetch(url);
  } catch {
    return { ok: false, error: `เชื่อมต่อ ${url} ไม่ได้` };
  }
  if (!res.ok) {
    return { ok: false, error: `HTTP ${res.status} จาก ${url}` };
  }

  // ข้อมูลจากภายนอกเก็บเป็น unknown ก่อนเสมอ
  let data: unknown;
  try {
    data = await res.json();
  } catch {
    return { ok: false, error: `ข้อมูลจาก ${url} ไม่ใช่ JSON` };
  }

  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    return { ok: false, error: z.prettifyError(parsed.error) };
  }
  return { ok: true, value: parsed.data };
}

// นับจำนวนสินค้าแต่ละหมวด ได้ครบทุกหมวดเพราะใช้ Record<Category, number>
export function countByCategory(products: readonly Product[]): Record<Category, number> {
  const counts = Object.fromEntries(CATEGORIES.map((c) => [c, 0])) as Record<Category, number>;
  for (const p of products) counts[p.category] += 1;
  return counts;
}

// คืนสินค้าที่ stock น้อยกว่า threshold เรียงจากน้อยไปมาก
export function lowStock(
  products: readonly Product[],
  threshold: number,
): Pick<Product, "id" | "name" | "stock">[] {
  return products
    .filter((p) => p.stock < threshold)
    .sort((a, b) => a.stock - b.stock)
    .map(({ id, name, stock }) => ({ id, name, stock }));
}

// Server จำลองบน 127.0.0.1 port 0 (ระบบเลือก port ว่างให้) ไม่ต้องใช้อินเทอร์เน็ต

  { id: "P-002", name: "ขนมปังกระเทียม", price: 35, stock: 2, category: "bakery" },

];

  { id: "P-001", name: "ชาเขียวนม", price: 45, stock: 12, category: "drink" },
  { id: "P-2", name: "ขนมปังกระเทียม", price: "35", stock: -2, category: "bakery" },
];

export type FakeServer = { baseUrl: string; close: () => Promise<void> };

export function startFakeServer(): Promise<FakeServer> {
  const server = createServer((req, res) => {
    if (req.url === "/products") {
      res.writeHead(200, { "content-type": "application/json" });
      res.end(JSON.stringify(GOOD));
    } else if (req.url === "/products-broken") {
      res.writeHead(200, { "content-type": "application/json" });
      res.end(JSON.stringify(BROKEN));
    } else if (req.url === "/not-json") {
      res.writeHead(200, { "content-type": "text/plain" });
      res.end("ระบบปิดปรับปรุง");
    } else {
      res.writeHead(404, { "content-type": "application/json" });
      res.end(JSON.stringify({ error: "not found" }));
    }
  });
  return new Promise((resolve) => {
    server.listen(0, "127.0.0.1", () => {
      const { port } = server.address() as AddressInfo;
      resolve({
        baseUrl: `http://127.0.0.1:${port}`,
        close: () => new Promise((done) => server.close(() => done())),
      });
    });
  });
}
