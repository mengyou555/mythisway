    สมชายต้องการเปลี่ยน SSH Server ในแล็บให้ Login ได้ด้วย Key เท่านั้น (PasswordAuthentication no) ลำดับขั้นตอนใดปลอดภัยที่สุดและไม่ทำให้ตัวเองถูกล็อกออกจากเครื่อง

    1. ตั้ง PasswordAuthentication no แล้ว Reload ทันที จากนั้นค่อยสร้าง Key ด้วย ssh-keygen และคัดลอก Public Key ขึ้นเครื่อง
    2. แก้ไฟล์ /etc/ssh/sshd_config หลักโดยตรง Restart Service ปิดทุก Session ที่เปิดอยู่ แล้วค่อยลอง Login ใหม่
    3. สร้าง Key และทดสอบ Login ด้วย Key ให้ผ่านก่อน แล้วเขียนค่าใน Drop-in 99-hardening.conf ตรวจด้วย sudo sshd -t เปิด Session เดิมค้างไว้ แล้วจึง Reload และทดสอบจาก Session ใหม่
    4. ปิด Firewall ทั้งหมดชั่วคราว ตั้งค่า แล้ว Reload เพื่อให้แน่ใจว่าไม่มีอะไรขวางการเชื่อมต่อ

    ทำไมระบบ Login ควรเก็บรหัสผ่านด้วย Argon2id แทนการเก็บ sha256(salt + password) แม้ว่าจะใส่ Salt แบบสุ่มแล้วก็ตาม

    1. เพราะ SHA-256 เป็นการเข้ารหัสที่ถอดกลับได้ แต่ Argon2id ถอดกลับไม่ได้

    4. เพราะ Argon2id ถูกออกแบบให้ช้าและใช้หน่วยความจำมากโดยตั้งใจ ถ้า Hash รั่วออกไป ผู้โจมตีจะเดารหัสผ่านแบบ Offline ได้ช้ากว่ามาก ส่วน SHA-256 คำนวณได้เร็วมากบน GPU

    สมชายรัน sudo tcpdump -i lo -nn -A บนเครื่องตัวเอง ขณะใช้ curl เรียก http://127.0.0.1:8000/ เขาเห็นข้อความ GET / HTTP/1.1 ชัดเจน แต่เมื่อเรียก https://127.0.0.1:8443/ ซึ่งเป็น openssl s_server จาก Part 2 เขาเห็นแต่ตัวอักษรอ่านไม่ออก เหตุผลคืออะไร

    1. tcpdump ไม่มีสิทธิ์ดักจับ Port ที่สูงกว่า 8000 จึงแสดงข้อมูลเสีย
    2. Port 8443 ใช้ TLS ข้อมูลระดับ Application จึงถูกเข้ารหัสหลัง Handshake ผู้ดักจับเห็นได้แค่ IP, Port และข้อมูลบางส่วนของ Handshake
    3. ข้อมูลบน Port ที่ลงท้ายด้วย 443 ถูกบีบอัด (Compress) อัตโนมัติโดย Linux Kernel
    4. curl ส่ง HTTP แบบ Binary ทุกครั้งที่ปลายทางเป็น Port ตัวเลขสี่หลัก

  11. ยาก

    Route /hello คืนค่าด้วยโค้ด return f"<h1>สวัสดี {name}</h1>" โดย name มาจาก Query String ของผู้ใช้ ข้อใดเป็นวิธีแก้ปัญหา XSS ที่ถูกต้องที่สุด

    1. ทำ Output Encoding โดยให้ Jinja2 Template ที่เปิด Autoescape แสดงค่า {{ name }} (หรือใช้ markupsafe.escape) และเพิ่ม Header Content-Security-Policy เป็นชั้นป้องกันที่สอง
    2. เปลี่ยนไปใช้ Template แล้วเขียน {{ name|safe }} เพื่อให้ Jinja2 ตรวจความปลอดภัยให้
    3. เขียน Blacklist ปฏิเสธทุก Request ที่มีคำว่า script ใน Query String
    4. แปลง name เป็น Base64 ก่อนแสดงผล เพื่อไม่ให้ Browser อ่านออก

File Integrity Monitor ขนาดเล็ก: รู้ทันทีเมื่อไฟล์ Config ถูกแก้

สถานการณ์

สมชายดูแลเครื่อง lab-ubuntu และเก็บไฟล์ Config สำคัญไว้ในโฟลเดอร์ watched/ ได้แก่ SSH Drop-in, ไฟล์ fail2ban และไฟล์ตัวอย่าง Environment ของแอป หลังเหตุการณ์ในคืนวันที่ 2026-10-20 หัวหน้าทีมอยากรู้ว่า "มีใครแอบแก้ไฟล์ Config หรือเพิ่มไฟล์แปลก ๆ เข้ามาไหม" เครื่องมือ File Integrity Monitoring (FIM) อย่าง AIDE หรือ Wazuh ทำงานนี้ในระบบจริง แต่ในโจทย์นี้ให้คุณเขียนเวอร์ชันเล็กด้วย Python Standard Library เพื่อเข้าใจหลักการ คือ "เก็บ Hash ของไฟล์ตอนที่รู้ว่าสะอาด (Baseline) แล้วเทียบกับ Hash ปัจจุบัน"

  1. เขียน fim.py ที่รับคำสั่งแบบ python3 fim.py init watched แล้วคำนวณ SHA-256 ของทุกไฟล์ในโฟลเดอร์ (รวมโฟลเดอร์ย่อย) บันทึกเป็น baseline.json โดยใช้ Path แบบ Relative เป็น Key
  2. เพิ่มคำสั่ง python3 fim.py check watched ที่เทียบไฟล์ปัจจุบันกับ Baseline แล้วพิมพ์สถานะของแต่ละไฟล์เป็น OK, MODIFIED, ADDED หรือ REMOVED เรียงตามชื่อไฟล์ พร้อมบรรทัดสรุปจำนวนแต่ละสถานะ
  3. กำหนด Exit Code ให้เอาไปใช้ต่อกับ cron หรือ CI ได้: 0 เมื่อไม่มีอะไรเปลี่ยน, 1 เมื่อพบการเปลี่ยนแปลง, 2 เมื่อหาโฟลเดอร์หรือ Baseline ไม่เจอ
  4. ทดสอบ: รัน init แล้ว check ทันที (ต้องได้ OK ทั้งหมด) จากนั้นจำลองเหตุการณ์ 3 อย่าง คือแก้ PermitRootLogin no เป็น yes, เพิ่มไฟล์ watched/ssh/authorized_keys_extra และลบ watched/app.env.example แล้ว check อีกครั้ง
  5. เพิ่มตัวเลือก --baseline ให้ระบุตำแหน่งไฟล์ Baseline เองได้ และอธิบายสั้น ๆ ว่าทำไมไม่ควรเก็บ Baseline ไว้ในโฟลเดอร์เดียวกับไฟล์ที่เฝ้าดู

SSH Policy Checker: ตรวจค่าที่มีผลจริงก่อน Reload

สถานการณ์

ทีมของสมชายใส่ไฟล์ 99-hardening.conf ที่ตั้ง PasswordAuthentication no ไว้แล้ว แต่ผลสแกนรอบล่าสุดกลับพบว่า Server ยังรับการ Login ด้วยรหัสผ่าน หัวหน้าทีมสงสัยว่ามีไฟล์อื่นใน sshd_config.d/ ทับค่าอยู่ (บน Ubuntu Image ที่สร้างด้วย cloud-init มักมีไฟล์ 50-cloud-init.conf) และสำหรับ Keyword ส่วนใหญ่ sshd ใช้กฎ "ค่าแรกที่เจอชนะ" (First Match Wins) ไม่ใช่ "ค่าสุดท้ายชนะ" แบบโปรแกรมทั่วไป งานของคุณคือเขียนตัวตรวจที่บอกได้ว่าค่าที่มีผลจริงของแต่ละ Key มาจากไฟล์ไหนบรรทัดไหน เพื่อใช้ตรวจก่อน Reload ทุกครั้ง

  1. เขียน ssh_policy_check.py ที่อ่าน lab/sshd_config ทีละบรรทัด ข้ามบรรทัดว่างและ Comment แยก Keyword (ไม่สนตัวพิมพ์เล็กใหญ่) กับค่า และรองรับรูปแบบ Key value กับ Key=value
  2. รองรับ Include: แทน /etc/ssh/ ด้วยโฟลเดอร์ที่ระบุผ่านตัวเลือก --etc-ssh แล้วอ่านไฟล์ที่ตรงกับ Pattern เรียงตามชื่อ (Lexical Order) ณ ตำแหน่งที่ Include อยู่ เหมือนที่ sshd ทำ
  3. ใช้กฎ First Match Wins: เก็บเฉพาะค่าแรกของแต่ละ Key พร้อมที่มา (ชื่อไฟล์:เลขบรรทัด) และหยุดอ่านเมื่อเจอ Match เพราะส่วนนั้นเป็นเงื่อนไขเฉพาะกลุ่ม ยกเว้น Keyword ที่ sshd สะสมค่าจากทุกบรรทัด ได้แก่ AllowUsers, DenyUsers, AllowGroups, DenyGroups และ AcceptEnv ให้ต่อค่าและที่มาของทุกบรรทัดเข้าด้วยกัน
  4. ตรวจตามนโยบาย 8 ข้อ: PermitRootLogin no, PasswordAuthentication no, KbdInteractiveAuthentication no, PubkeyAuthentication yes, X11Forwarding no, MaxAuthTries ไม่เกิน 3, LoginGraceTime ไม่เกิน 30 วินาที (รองรับรูปแบบ 30, 30s, 2m) และ AllowUsers มี somchai ถ้า Key ใดไม่ถูกตั้งเลย ให้ใช้ค่า Default ของ OpenSSH 9.6 และแสดงที่มาว่า (ค่า default)
  5. พิมพ์ตาราง STATUS / KEY / EXPECT / ACTUAL / SOURCE และบรรทัดสรุป แล้วจบด้วย Exit Code 1 ถ้ามี FAIL อย่างน้อยหนึ่งข้อ
  6. แก้ Config ใน lab/ ให้ผ่านทุกข้อ แล้วยืนยันผลกับ sshd ตัวจริงด้วย sshd -T ถ้าเครื่องคุณติดตั้ง openssh-server ไว้

#!/usr/bin/env python3
"""fim.py - File Integrity Monitoring ขนาดเล็ก (ใช้เฉพาะ stdlib)"""
import argparse
import hashlib
import json
import sys
from datetime import datetime, timezone
from pathlib import Path


def sha256_of(path: Path) -> str:
    # อ่านไฟล์แบบ binary แล้วคำนวณ SHA-256 (file_digest มีตั้งแต่ Python 3.11)
    with path.open("rb") as f:
        return hashlib.file_digest(f, "sha256").hexdigest()


def scan(folder: Path) -> dict[str, str]:
    # เดินทุกไฟล์ในโฟลเดอร์ (รวมโฟลเดอร์ย่อย) เก็บเป็น {path แบบ relative: hash}
    result = {}
    for p in sorted(folder.rglob("*")):
        if p.is_file():
            result[p.relative_to(folder).as_posix()] = sha256_of(p)
    return result


def cmd_init(folder: Path, baseline: Path) -> int:
    hashes = scan(folder)
    data = {
        "folder": str(folder.resolve()),
        "created": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "algorithm": "sha256",
        "files": hashes,
    }
    baseline.write_text(json.dumps(data, indent=2, ensure_ascii=False), encoding="utf-8")
    print(f"[INIT] บันทึก baseline {len(hashes)} ไฟล์ ลงใน {baseline}")
    return 0

    # รวมชื่อไฟล์จากทั้งสองฝั่ง แล้วเรียงเพื่อให้ผลลัพธ์คงที่ทุกครั้ง
    for name in sorted(old.keys() | new.keys()):
        if name not in new:
            status = "REMOVED"
        elif name not in old:
            status = "ADDED"
        elif old[name] != new[name]:
            status = "MODIFIED"
        else:
            status = "OK"
        counts[status] += 1
        print(f"{status:<9} {name}")
    print("-" * 40)
    print("สรุป: " + ", ".join(f"{k}={v}" for k, v in counts.items()))
    changed = counts["MODIFIED"] + counts["ADDED"] + counts["REMOVED"]
    # exit code 0 = ไม่มีอะไรเปลี่ยน, 1 = มีการเปลี่ยนแปลง (เอาไปต่อกับ cron หรือ CI ได้)
    return 1 if changed else 0


def main() -> int:
    ap = argparse.ArgumentParser(description="ตรวจว่าไฟล์ในโฟลเดอร์ถูกแก้ไขหรือไม่")
    ap.add_argument("command", choices=["init", "check"])
    ap.add_argument("folder", type=Path)
    ap.add_argument("--baseline", type=Path, default=Path("baseline.json"))
    args = ap.parse_args()
    if not args.folder.is_dir():
        print(f"[ERROR] ไม่พบโฟลเดอร์: {args.folder}", file=sys.stderr)
        return 2
    if args.command == "init":
        return cmd_init(args.folder, args.baseline)
    return cmd_check(args.folder, args.baseline)


if __name__ == "__main__":
    sys.exit(main())

  • Hash คือลายนิ้วมือของไฟล์: แก้ไฟล์แค่ตัวอักษรเดียว SHA-256 ก็เปลี่ยนทั้งค่า (Avalanche Effect) จึงไม่ต้องเก็บสำเนาไฟล์ทั้งไฟล์ไว้เทียบ เก็บแค่ Hash ขนาด 64 ตัวอักษรก็พอ
  • Baseline ต้องสร้างตอนที่มั่นใจว่าระบบสะอาด: ถ้าสร้างหลังถูกแก้แล้ว Baseline ก็จะยืนยันว่าไฟล์ที่ถูกแก้คือ "ปกติ"

  • Exit Code คือภาษากลางของระบบอัตโนมัติ: cron, systemd timer หรือ CI ดู Exit Code เพื่อตัดสินว่าจะส่ง Alert หรือไม่ การแยก 1 (พบการเปลี่ยนแปลง) กับ 2 (เครื่องมือทำงานไม่ได้) ช่วยให้ Triage ง่ายขึ้น

โค้ดใช้เฉพาะ Python Standard Library (argparse, glob, re, pathlib) อ่านไฟล์ในโฟลเดอร์แล็บเท่านั้น ไม่แก้ไขอะไรในระบบ

#!/usr/bin/env python3
"""ssh_policy_check.py - ตรวจค่า "ที่มีผลจริง" ของ sshd_config เทียบกับนโยบาย Hardening"""
import argparse
import glob
import re
import sys
from pathlib import Path

# ค่า default ของ OpenSSH 9.6 สำหรับ key ที่เราตรวจ (ใช้เมื่อไม่มีไฟล์ใดตั้งค่าไว้)
DEFAULTS = {
    "permitrootlogin": "prohibit-password",
    "passwordauthentication": "yes",
    "kbdinteractiveauthentication": "yes",
    "pubkeyauthentication": "yes",
    "x11forwarding": "no",
    "maxauthtries": "6",
    "logingracetime": "120",
    "allowusers": "",
}

# นโยบาย: (key, วิธีตรวจ, ค่าที่ต้องการ)
POLICY = [
    ("permitrootlogin", "eq", "no"),
    ("passwordauthentication", "eq", "no"),
    ("kbdinteractiveauthentication", "eq", "no"),
    ("pubkeyauthentication", "eq", "yes"),
    ("x11forwarding", "eq", "no"),
    ("maxauthtries", "max", 3),
    ("logingracetime", "max", 30),
    ("allowusers", "has", "somchai"),
]

# key กลุ่มนี้ sshd ไม่ใช้กฎ first match wins แต่ "สะสม" ค่าจากทุกบรรทัด
ACCUMULATE = {"allowusers", "denyusers", "allowgroups", "denygroups", "acceptenv"}


def to_seconds(text: str) -> int:
    # แปลงรูปแบบเวลาของ sshd เช่น 30, 30s, 2m, 1h เป็นวินาที
    m = re.fullmatch(r"(\d+)([smh]?)", text.strip().lower())
    if not m:
        raise ValueError(f"รูปแบบเวลาไม่ถูกต้อง: {text!r}")
    return int(m.group(1)) * {"": 1, "s": 1, "m": 60, "h": 3600}[m.group(2)]


def expand_include(pattern: str, etc_dir: Path) -> list[Path]:
    # sshd ตีความ path แบบ relative ว่าอยู่ใต้ /etc/ssh
    # ในแล็บเราแทน /etc/ssh ด้วยโฟลเดอร์ etc_dir เพื่อไม่ต้องแตะไฟล์ระบบจริง
    if pattern.startswith("/etc/ssh/"):
        pattern = str(etc_dir / pattern[len("/etc/ssh/"):])
    elif not pattern.startswith("/"):
        pattern = str(etc_dir / pattern)
    return [Path(p) for p in sorted(glob.glob(pattern))]


def parse(path: Path, etc_dir: Path, effective: dict) -> bool:
    """อ่านไฟล์ทีละบรรทัด เก็บเฉพาะค่าแรกที่เจอของแต่ละ key (กฎ first match wins)
    ยกเว้น key ใน ACCUMULATE ที่ต่อค่าจากทุกบรรทัดเหมือน sshd
    คืนค่า False เมื่อเจอ Match block เพื่อหยุดอ่าน (ส่วนนั้นเป็นเงื่อนไขเฉพาะกลุ่ม)"""
    for no, raw in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
        line = raw.strip()
        if not line or line.startswith("#"):
            continue
        parts = re.split(r"\s*=\s*|\s+", line, maxsplit=1)
        key = parts[0].lower()
        value = parts[1].strip() if len(parts) > 1 else ""
        if key == "include":
            for pattern in value.split():
                for inc in expand_include(pattern, etc_dir):
                    if not parse(inc, etc_dir, effective):
                        return False
            continue
        if key == "match":
            return False
        if key in ACCUMULATE and key in effective:
            # key แบบสะสม: ต่อค่าใหม่ท้ายค่าเดิม และเก็บที่มาไว้ครบทุกจุด
            old_value, old_source = effective[key]
            effective[key] = (f"{old_value} {value}", f"{old_source},{path.name}:{no}")
            continue
        # key ทั่วไป: เก็บเฉพาะครั้งแรก ค่าที่มาทีหลังถูกเพิกเฉย
        effective.setdefault(key, (value, f"{path.name}:{no}"))
    return True


def check(effective: dict) -> list[tuple]:
    rows = []
    for key, rule, want in POLICY:
        value, source = effective.get(key, (DEFAULTS[key], "(ค่า default)"))
        if rule == "eq":
            ok = value.lower() == want
            expect = want
        elif rule == "max":
            ok = to_seconds(value) <= want if key == "logingracetime" else int(value) <= want
            expect = f"<= {want}"
        else:  # has
            ok = want in value.split()
            expect = f"มี {want}"
        rows.append(("PASS" if ok else "FAIL", key, expect, value or "(ว่าง)", source))
    return rows


def main() -> int:
    ap = argparse.ArgumentParser(description="ตรวจ sshd_config ตามนโยบาย Hardening")
    ap.add_argument("config", type=Path, help="ไฟล์ sshd_config หลัก")
    ap.add_argument("--etc-ssh", type=Path, default=Path("/etc/ssh"),
                    help="โฟลเดอร์ที่ใช้แทน /etc/ssh (สำหรับแล็บ)")
    args = ap.parse_args()
    if not args.config.is_file():
        print(f"[ERROR] ไม่พบไฟล์: {args.config}", file=sys.stderr)
        return 2
    effective: dict = {}
    parse(args.config, args.etc_ssh, effective)
    rows = check(effective)
    print(f"{'STATUS':<6} {'KEY':<29} {'EXPECT':<11} {'ACTUAL':<18} SOURCE")
    for r in rows:
        print(f"{r[0]:<6} {r[1]:<29} {r[2]:<11} {r[3]:<18} {r[4]}")
    fails = sum(1 for r in rows if r[0] == "FAIL")
    print(f"\nผลรวม: PASS {len(rows) - fails} / FAIL {fails}")
    return 1 if fails else 0


if __name__ == "__main__":
    sys.exit(main())

sshd แสดง allowusers สองบรรทัด แปลว่าทั้ง malee และ somchai Login ได้ ตัวตรวจของเรารายงานตรงกันพร้อมที่มาครบทั้งสองไฟล์ ถ้าใช้กฎ First Match Wins กับ AllowUsers ด้วย ตัวตรวจจะเห็นแค่ malee จาก 60-team.conf แล้วรายงาน FAIL ว่าไม่มี somchai ทั้งที่ sshd ยังอนุญาต somchai อยู่ นี่คือเหตุผลที่ต้องแยก Keyword กลุ่ม ACCUMULATE ออกมา

แนวคิด
  • ตรวจ "ค่าที่มีผลจริง" ไม่ใช่ "ค่าที่เราเขียน": การ grep หาคำว่า PasswordAuthentication no ในไฟล์ของเราจะเจอและดูเหมือนผ่าน แต่ไม่ได้บอกว่ามีไฟล์อื่นชนะอยู่ ตัวตรวจจึงต้องจำลองลำดับการอ่านแบบเดียวกับ sshd
  • First Match Wins ด้วย setdefault: dict.setdefault เขียนค่าเฉพาะเมื่อ Key ยังไม่มี จึงตรงกับกฎของ sshd สำหรับ Keyword ส่วนใหญ่โดยไม่ต้องเขียน if เพิ่ม ส่วน Keyword ใน ACCUMULATE ต้องต่อค่าแทน เพราะ sshd สะสมค่าเหล่านี้จากทุกบรรทัด ถ้าใช้ setdefault กับ AllowUsers ด้วย ผู้ใช้ที่ถูกอนุญาตในไฟล์ถัดไปจะหายไปจากรายงาน ทั้งที่ Login ได้จริง
  • Include แบบ Recursive ตามตำแหน่ง: ไฟล์ที่ Include ถูกอ่าน "ณ ตำแหน่งของบรรทัด Include" และเรียงชื่อด้วย sorted() ค่าใน Drop-in จึงชนะค่าที่อยู่หลังบรรทัด Include ในไฟล์หลัก เช่น X11Forwarding yes
  • บอกที่มาของค่าทุกครั้ง: คอลัมน์ SOURCE ทำให้แก้ได้ตรงจุดทันที ไม่ต้องเดาว่าไฟล์ไหนผิด เป็นหลักเดียวกับ Alert ที่ดีใน SOC ที่ต้องมีหลักฐานแนบเสมอ
  • ใช้ค่า Default เมื่อไม่มีการตั้งค่า: การไม่ตั้งค่าไม่ได้แปลว่าปลอดภัย MaxAuthTries ที่ไม่ได้ตั้งจะเป็น 6 ตัวตรวจจึงต้องรู้ค่า Default ด้วย
  • หยุดที่ Match: ค่าใน Match Block มีผลเฉพาะผู้ใช้หรือ Address ที่ตรงเงื่อนไข เวอร์ชันนี้จึงตรวจเฉพาะค่าระดับ Global ซึ่งเป็นข้อจำกัดที่ต้องบอกไว้ในเอกสาร

"""app.py - เวอร์ชันแก้ไขแล้วของ vuln_app.py"""
import os
import sqlite3

from flask import Flask, jsonify, render_template_string, request

MAX_NAME_LEN = 50
DB_PATH = os.environ.get("SHOP_DB", "shop.db")

HELLO_TEMPLATE = "<h1>สวัสดี {{ name }}</h1>"   # Jinja2 จะ escape ค่า name ให้อัตโนมัติ


def create_app() -> Flask:
    app = Flask(__name__)

    # แก้ปัญหา 1: อ่าน SECRET_KEY จาก environment ถ้าไม่มีให้หยุดทันที (fail closed)
    secret = os.environ.get("SECRET_KEY")
    if not secret:
        raise RuntimeError("SECRET_KEY is not set")
    app.config.update(
        SECRET_KEY=secret,
        SESSION_COOKIE_HTTPONLY=True,
        SESSION_COOKIE_SAMESITE="Lax",
        SESSION_COOKIE_SECURE=True,
    )

    def bad_input(name: str) -> bool:
        # input validation เป็นชั้นป้องกันเสริม ไม่ใช่ตัวแทนของ parameterized query
        return len(name) > MAX_NAME_LEN

    @app.get("/products")
    def products():
        name = request.args.get("name", "")
        if bad_input(name):
            return jsonify(error="invalid input"), 400
        conn = sqlite3.connect(DB_PATH)
        try:
            # แก้ปัญหา 2: ใช้ placeholder ? และส่งค่าเป็น tuple 1 ตัว
            rows = conn.execute(
                "SELECT id, name, price FROM products WHERE name = ?", (name,)
            ).fetchall()
        finally:
            conn.close()
        return jsonify([{"id": r[0], "name": r[1], "price": r[2]} for r in rows])

    @app.get("/hello")
    def hello():
        name = request.args.get("name", "guest")
        if bad_input(name):
            return "invalid input", 400
        # แก้ปัญหา 3: ให้ template engine ทำ output encoding (ห้ามใช้ |safe กับข้อมูลผู้ใช้)
        return render_template_string(HELLO_TEMPLATE, name=name)

    @app.errorhandler(500)
    def server_error(_err):
        # ข้อความกลาง ๆ ไม่เปิดเผย stack trace หรือชื่อตาราง
        return jsonify(error="internal error"), 500

    @app.after_request
    def security_headers(resp):
        # แก้ปัญหา 4: เพิ่ม security headers ทุก response
        resp.headers["Content-Security-Policy"] = "default-src 'self'"
        resp.headers["X-Content-Type-Options"] = "nosniff"
        resp.headers["Referrer-Policy"] = "no-referrer"
        resp.headers["X-Frame-Options"] = "DENY"
        return resp

    return app


if __name__ == "__main__":
    # แก้ปัญหา 5: bind เฉพาะ 127.0.0.1 และปิด debug
    create_app().run(host="127.0.0.1", port=5000, debug=False)
