    ทำไมหัวข้อเหล่านี้ถึงเชื่อมกัน

    เส้นเชื่อมเหตุผล
    Linux → ทุกอย่างServer, Cloud, Docker และเครื่องมือ AI ส่วนใหญ่รันบน Linux ถ้าใช้ Terminal ไม่คล่อง ทุกหัวข้อที่เหลือจะติดขัด
    Git → ทุกอย่างงานโค้ดทุกชิ้นต้องเก็บใน Git และ GitHub คือ Portfolio ที่บริษัทเปิดดูจริง
    Python → AI / Data / Securityไลบรารี AI และ Data เกือบทั้งหมด (pandas, scikit-learn, PyTorch) รวมถึงเครื่องมือ Security จำนวนมากเขียนด้วย Python
    JavaScript → TypeScript → Node.jsTypeScript คือ JavaScript ที่เพิ่ม Type ส่วน Node.js คือการรัน JavaScript ฝั่ง Server ต้องรู้ JS ก่อนจึงจะเข้าใจสองอย่างหลัง
    Network → API DesignAPI ทำงานบน HTTP ซึ่งทำงานบน TCP/IP อีกที ถ้าไม่รู้ว่า Request เดินทางอย่างไร จะ Debug API ไม่ได้
    SQL + API → BackendBackend คือการรับ Request ผ่าน API แล้วอ่าน/เขียนข้อมูลใน Database แล้วตอบกลับ ต้องมีครบทั้งสองอย่าง
    Prompt → Vibe Coding / AI Engineer / AI Agentsทั้งสามหัวข้อคือการ "สั่ง AI" ในระดับที่ซับซ้อนขึ้นเรื่อยๆ
    ทุกอย่าง → Cyber Securityถ้าไม่รู้ว่าระบบทำงานอย่างไร ก็ไม่มีทางรู้ว่ามันพังหรือถูกโจมตีได้อย่างไร Security จึงต่อยอดจากความรู้ทุกด้าน

      STEP 2

      ติดตั้ง WSL2 + Ubuntu 24.04 LTS

      คลิกขวาที่ปุ่ม Start แล้วเลือก Terminal (Admin) บน Windows 11 หรือ Windows PowerShell (Admin) บน Windows 10

wsl --list --online

# ติดตั้ง WSL2 พร้อม Ubuntu 24.04 LTS (เวอร์ชันที่หลักสูตรนี้ใช้)
wsl --install -d Ubuntu-24.04

      เมื่อติดตั้งเสร็จให้ Restart เครื่อง

      หมายเหตุ

      ถ้าพิมพ์แค่ wsl --install โดยไม่ใส่ -d ตอนนี้จะได้ Ubuntu 26.04 LTS หลักสูตรนี้จึงระบุ -d Ubuntu-24.04 ไว้ คำสั่งนี้ยังใช้ได้และจะติดตั้ง 24.04.5

      ระวัง

      ถ้าเครื่องเคยติดตั้ง WSL มาก่อน ให้รัน wsl --update ก่อนติดตั้ง เพราะ WSL รุ่นเก่าไม่รู้จักชื่อ Ubuntu-24.04 ถ้าติดตั้งแล้วค้างที่ 0.0% ให้ใช้ wsl --install --web-download -d Ubuntu-24.04 แทน

      0.11Tech Stack และเวอร์ชันที่ใช้ในหลักสูตร

      หลักการเลือกเวอร์ชัน

      1. ใช้รุ่น Stable หรือ LTS เท่านั้น ไม่ใช้ Beta หรือ RC เพราะมือใหม่ควรเจอแต่ Bug ของตัวเอง ไม่ควรเจอ Bug ของเครื่องมือ
      2. ถ้าเวอร์ชันใน apt ใช้ได้ ให้ใช้จาก apt เพราะติดตั้งง่ายและ Ubuntu อัปเดตความปลอดภัยให้เอง
      3. ถ้า apt มีแต่รุ่นเก่าเกินไป (เช่น Node.js และ Go) ให้ใช้ตัวติดตั้งทางการของภาษานั้น
      4. โค้ดทุกชิ้นในหลักสูตรจะระบุเวอร์ชันที่ใช้ ถ้ารันแล้วผลไม่ตรง ให้เช็กเวอร์ชันก่อนเป็นอย่างแรก
